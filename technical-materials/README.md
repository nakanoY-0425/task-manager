## 目的（2026-10-31、裕貴さんの説明を受けて再整理）

このフォルダの役割は「教科書をそのまま完成させて出す」ことではない。**裕貴さんが動画・YouTubeコンテンツを外注で作る際に、必要な部分を取り出して構成するための「素材プール」**として使う。したがって、各講義を一言一句磨き上げる必要はなく、使える部分を正確に・ノイズなく拾い出せる状態にしておくことが目的。

**裕貴さん本人の評価（2026-10-31確認）**：A知識1-1-1〜1-1-12の内容は、**基本的に一般的なパーソナルトレーナー教育の知識がメイン**であり、裕貴さん独自と言えるのは実質的に「トレーニングの技術的な内容・考え方」の部分（NEOS Plus／NRTの実技とその思想）に限られる。その核心部分は、**実際に受けてみるか、裕貴さん自身が動画で説明しないと伝わらない**性質のものであり、現時点のA知識・B技術のテキスト資料だけでは再現できない。したがって：
- A知識（1-1-1〜1-1-12）＝**一般知識の素材プール**。お客様・受講生向け動画の「周辺知識パート」（栄養・解剖の基礎、安全管理、ビジネスマインド等）の下敷きとして使う。
- B技術（NRT実技）＝**裕貴さん独自の差別化コンテンツ**。現時点では胸の4種目のみで、裕貴さんから「もう少し待ってほしい」と連絡あり（2026-10-31）、追加提供待ち。将来的にはここが動画の核になる見込み。

## フォルダ構成

```
technical-materials/
  README.md                  … このファイル
  source/
    original_pdf/             … 原本PDF（改変しない）
    extracted_text/           … 機械抽出テキスト（誤字・図表欠落・抽出順の乱れがあり得る。疑わしい箇所は原本PDFを確認する）
  source_inventory.md         … 講義名・ページ数・原本対応
  curriculum_map.md           … A〜Dの暫定マップ、確定と未確定の区別
  issues_for_review.md        … 科学的根拠・表現・安全性・重複・誤植の要確認リスト
  lectures/                   … 各講義の設計案（原本と改善案を対照表示）
```

## 作業原則（引継指示書より）

1. `source/original_pdf/`の原本は改変しない。
2. `source/extracted_text/`は機械抽出テキスト。誤字・図表欠落・抽出順の乱れがあり得るため、必ず原本PDFの該当ページを確認する。
3. まずファイル別の目次、ページ別要約、教材間の重複と欠落を整理する。
4. 科学的な事実、独自メソッドの主張、未検証の効果表現を明確に区別する。特に「1セットで3セットの効果」「血圧の急上昇が少ない」等は検証・承認前に断定表現へ書き換えない。
5. 既存教材の思想や手順は無断で削除・変更せず、改善提案は別案として提示し承認を得る。
6. 各講義の設計は①講義目的 ②学習ゴール ③スライド構成 ④各スライド詳細（タイトル・本文・図解・イラスト・ナレーション・補足）⑤制作指示（レイアウト・デザイン・画像・アイコン・PowerPoint仕様）の順。
7. 優先順位：わかりやすさ > 教育効果 > 再現性 > 商品価値 > デザイン。
8. 出力は編集可能なPowerPointを想定し、図形・テキストを可能な限り編集可能な状態で構成する（2026-10-31時点ではテキストベースで先行、PowerPoint化は次の段階）。元PDFにある画像は権利・品質を確認する。
9. 医学・運動指導に関する安全性と正確性を確認し、疑義を`issues_for_review.md`に記載する。
