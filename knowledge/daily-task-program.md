# 課題提出型・日次タスク設計｜6ヶ月／12ヶ月コース

このファイルは、個別コンサル事業（1章、6ヶ月598,000円／12ヶ月980,000円）を「課題提出型」で運用するための日次タスク設計です。目的は、知識を渡すだけで終わらせず、**毎日の行動を課し、提出させ、監視し、絶対に実行させる**こと。

裕貴さんが別途管理しているタスク表（Excel/スプレッドシート）に、この設計の内容をそのまま入れ込む前提で作成している。日付・列などの形式は裕貴さん側のタスク表に合わせる。

参照元：CLAUDE.md 1章（個別コンサル事業）、既存の6ヶ月／12ヶ月ワークブック（フェーズ0〜9）、分野別ロードマップ6冊（商品設計・地上戦・SNS受け皿・セールス・継続紹介・週次KPI管理）、`knowledge/pt-coaching-marketing-knowledge.md`（コーチングの質問集）

---

## 0. 設計方針

- **365日／180日を1日ごとに完全にユニークな内容で書き切ることはしない**。曜日ごとに固定のタスク種別（テンプレ）を決め、週単位で進行するフェーズに応じて具体的な内容を差し込む「曜日テンプレ×週単位のフェーズ進行」方式で設計する。
- 週の中の同じ曜日には、フェーズが変わっても**同じ役割のタスク**が来る（例：毎週月曜は「週次計画＋前週の数字提出」）。これにより受講生にとって「型」が体に染みつき、コーチ側も毎週何を確認すればいいかが一定になる。
- **すべてのタスクは「提出」を伴う**。提出がなければ実行したかどうかが分からないため、提出そのものを行動管理の核に置く。
- 既存のフェーズ構成（0〜5＝6ヶ月共通、6〜9＝12ヶ月後半）と1章の設計方針（12ヶ月後半は固定カリキュラムにせず本人の状態で内容を決める）に完全準拠する。

## 0.5 コーチング頻度（2026-09-09確定）

コース期間によってコーチングセッションの頻度が異なる。**タスクの内容（フェーズの課題）は共通だが、コーチングの頻度だけがコース期間で分岐する**点に注意。

- **6ヶ月コース**：最初の3ヶ月（Week1〜13）＝週1回30分。3ヶ月目以降〜6ヶ月（Week14〜26）＝月2回（隔週ペース）。
- **12ヶ月コース**：最初の6ヶ月（Week1〜26）＝週1回30分。残り6ヶ月（Week27〜52）＝月2回（隔週ペース）。

つまりWeek14〜26は、6ヶ月コース生にとっては「月2回に切り替わった後」だが、12ヶ月コース生にとっては「まだ週1回のまま」。同じ週番号でもコース期間によってコーチングの有無が変わるため、下記の週次表・日次表では**コース別に「コーチングの日」を別々に確認する**必要がある。

「月2回」の運用は、隔週（2週に1回）を基本とする。以下の週次表・日次表では、Week14以降の「コーチング」欄に◯（週1回コースの場合に実施）と隔週◯（月2回コースの場合に実施）を併記する。

## 1. 毎日の課題提出フォーマット（行動監視の核）

すべての日次課題は、以下の5項目をセットで提出させる。フォーマットを固定することで、コーチ側が毎日全員分を素早く確認できる。

1. 今日の課題は何だったか
2. 実施したか（YES / NO）
3. 実施した場合の結果・数字（件数・時間など）
4. 実施できなかった場合の理由（一言でよい、理由なしは不可）
5. 明日の予定

提出手段は、既存のChatwork／LINE等の運用に合わせる（本ファイルでは手段は指定しない）。

## 2. 未提出・未実行時のエスカレーションルール（行動を強制する仕組み）

- **1日未提出**：翌朝、リマインド送信（自動化できる場合は自動、できない場合はコーチ手動）
- **3日連続未提出、または3日連続「実施：NO」**：コーチから直接連絡。`pt-coaching-marketing-knowledge.md` 7章・8章の「リミティング・ビリーフを崩す質問」（それは事実ですか、それとも解釈ですか？／もしその制限が存在しなかったら何をしますか？等）を使って、行動できない本当の原因を特定する。
- **週内の提出率が50%未満**：その週のコーチングセッション（毎週土または日）で、行動できない原因を最優先の議題にする。課題を増やすのではなく、`pt-coaching-marketing-knowledge.md` 53章「課題は絞る」に従い、翌週は課題を1つに絞る。
- **2週連続で提出率50%未満**：1章に定める受講条件（「日報・週報の提出やタスク実行などの受講条件を満たす受講生に対して行う伴走支援」）に基づき、サポート継続の扱いをどうするか、本人と話し合う対象として扱う。**契約上の具体的な措置（一時停止・打ち切り等）は本ファイルでは決めず、裕貴さんの判断事項とする**。

## 3. コーチングセッションでの確認（毎週土または日）

週1回のコーチングセッションでは、`pt-coaching-marketing-knowledge.md` 15章・16章のセッション開始/終了質問をそのまま使う。

- 開始時：前回から何がありましたか？／うまくいったことは何ですか？／できなかったことは何ですか？／なぜできなかったと思いますか？
- 終了時：今日一番大きかった気づきは何ですか？／次回までに何をしますか？／期限はいつですか？／数字で測るとどうなりますか？

## 5. 曜日別タスク・メニュー（フェーズごと、6ヶ月コース）

### フェーズ0｜経営診断・オンボーディング（Week1のみ）
- **月**：オンボーディング面談（コーチ実施）。生徒は現在の売上・顧客数・単価・稼働時間・集客方法をヒアリングシートに記入して提出
- **火**：過去に試した集客・セールス施策の棚卸しを提出（何を試し、何がうまくいき、何がうまくいかなかったか）
- **水**：3ヶ月後・6ヶ月後・1年後の理想（月商・顧客数・働き方）を`pt-coaching-marketing-knowledge.md`4章の質問に沿って記入し提出
- **木**：今、一番困っていること・最大の障害を言語化して提出（6章の質問を使う）
- **金**：フェーズ0まとめ、コーチからのフィードバック確認
- **土**：週次コーチングセッション
- **日**：休み

### フェーズ1｜商品設計（Week2〜3）
- **月**：商品設計8項目のうちWHO／WHATを記入して提出
- **火**：RESULT／HOWを記入して提出
- **水**：PERIOD／PRICEを記入して提出
- **木**：SUPPORT／DIFFERENCEを記入して提出
- **金**：完成した商品設計8項目を「1分で説明できるか」練習し、音声または動画で提出（商品設計ロードマップ完成チェックリスト5項目も確認）
- **土**：週次コーチングセッション
- **日**：休み

（Week3は高単価化の検討・よくある失敗4パターンのチェック・ワークシート仕上げに充てる）

### フェーズ2｜集客導線構築：地上戦＋SNS受け皿（Week4〜9、6週）
- **月**：週次KPI入力（フェーズ5と連動）＋今週の地上戦アプローチ目標件数・SNS投稿計画を提出
- **火**：地上戦アプローチ実施（提携候補への接触、週10件ペース）→件数と結果を提出
- **水**：SNS投稿1本（悩み系または教育系）を投稿→提出、ストーリー投稿の実施記録
- **木**：既存客・卒業生への近況確認連絡（週5件ペース）を実施→提出
- **金**：SNS投稿1本（実績系またはCTA系）を投稿→提出。JV商談を実施した週はその記録も提出
- **土**：週次振り返り・コーチングセッション
- **日**：休み

### フェーズ3準備｜セールス台本構築（Week10〜13）
- **月**：13ステップ台本の音読練習を実施→提出
- **火**：悩みの深掘り台本を自分の言葉で作成→提出
- **水**：理想未来・価格提示の台本を作成→提出
- **木**：反論対応の台本を作成、知人相手にロールプレイを実施→提出
- **金**：クロージングの3つの質問を使った練習記録を提出
- **土**：週次コーチングセッション
- **日**：休み

### フェーズ3実践｜体験セッション・セールス実践期（Week14〜20、7週）
- **月**：週次KPI入力＋今週の体験セッション目標件数を提出
- **火**：地上戦アプローチを継続（フェーズ2の火のメニューを継続、週10件ペース維持）
- **水**：体験セッション実施（実施した場合）→当日中フォロー連絡の実施記録を提出
- **木**：SNS投稿を継続（フェーズ2の水・金のメニューを継続）
- **金**：成約・失注の結果と理由を提出
- **土**：週次振り返り。**コーチングは6ヶ月コース＝月2回（隔週）、12ヶ月コース＝週1回のまま**（0.5章参照）。コーチングがない週は振り返りのみ自己提出。
- **日**：休み

### フェーズ4｜継続・紹介の仕組み化（Week21〜24、4週）
- **月**：継続プラン案内の運用ルール（契約終了1ヶ月前に案内、というタイミングの実践確認）を提出
- **火**：セッション内で使う紹介依頼の一言テンプレを作成→提出
- **水**：紹介料条件（金額・支払いタイミング）の運用フローを確認・整理して提出
- **木**：既存客への継続案内・紹介依頼を実際に実施した件数を提出
- **金**：解約理由・顧客満足度の確認結果（該当があれば）を提出
- **土**：週次振り返り。**コーチングは6ヶ月コース＝月2回（隔週）、12ヶ月コース＝週1回のまま**（0.5章参照）
- **日**：休み

### フェーズ5｜週次KPI管理（全期間、毎週土または日に実施）
- KPI12項目（売上／新規問い合わせ／体験予約／体験実施／成約数／成約率／新規顧客単価／既存顧客数／継続率／紹介数／営業件数／提携アプローチ件数）を入力
- 前週・目標と比べて崩れた指標を特定し、理由を一言メモ
- 翌週のアプローチ件数・体験枠の目標を数字で更新して提出

### Week25〜26｜振り返り・次段階の判断
- 6ヶ月間の成果（売上・成約数・継続率等）をまとめて提出
- 成果事例シート（データ蓄積用、1章「データ蓄積の仕組み」と連動）を作成して提出
- 卒業／経営構築延長／コンサル込みプランへ移行、いずれを希望するかの意向を確認（このタイミングで初めて分岐・差額精算の話を案内する。CLAUDE.md 1章の非公開ルールに従い、それまでは開示しない）
- 最終コーチングセッション

## 6. 12ヶ月コース｜後半26週（Week27〜52）の設計方針

CLAUDE.md 1章「12ヶ月コース後半6ヶ月の設計方針」に従い、**後半26週も固定の月割りカリキュラムにはしない**。Week26時点の結果によって分岐する。

**コーチング頻度（0.5章と連動）**：Week27から、12ヶ月コースもコーチングが**週1回→月2回（隔週）**に切り替わる。これは「結果が出ている／出ていない」の分岐とは別に、全受講生に共通で適用される頻度ルール。

### 結果が出ている受講生（月商目標に近い、またはすでに到達）
- フェーズ2〜5（集客・セールス・継続・KPI管理）の曜日メニューを、目標値を引き上げた上で継続する
- 加えて、**日曜をフェーズ6・7の学習日**として追加する：
  - フェーズ6（経験の棚卸し）：Week27〜30。自分がやってきたことを言語化する課題を日曜に配置（何をやって結果が出たか／再現できる形で書けるか）
  - フェーズ7（コンサルの基礎・型を渡す）：Week31〜34。ワークブック・実行チェックリスト・実行ロードマップを「他のトレーナーに渡せる形」に整理する課題を日曜に配置
  - 本格的にコンサルを始めたい受講生には、追加オプション（1章に記載、金額未確定）の案内をこの時点で行う

### 6ヶ月時点で結果が出ていない受講生
- コンサル養成は行わず、フェーズ2〜4（集客・セールス・継続）のサイクルをそのまま繰り返す
- 目標値は下げず、むしろ「今どの数字が一番のボトルネックか」（`pt-coaching-marketing-knowledge.md` 54章）を毎週のコーチングで再確認し、施策を絞り直す
- Week51〜52で12ヶ月終了時点の振り返りを行い、継続プラン＋αの必要性を判断する（1章に記載、金額・ルール未確定のため、この時点でも社内検討事項として扱う）

### 共通（フェーズ8・9）
- **フェーズ8（コンサル実施ログ）**：コンサルを開始した受講生のみ、月2回（第2・第4土曜等）実施ログの提出を追加
- **フェーズ9（月次KPI管理）**：フェーズ5の週次KPIに加えて、月末に月次まとめを提出（毎月最終日曜）

## 7. この設計をタスク表に入れ込む際の使い方

1. タスク表の日付列に対して、上記「週」を割り当てる（Week1＝1〜7日目、Week2＝8〜14日目、以降同様）
2. その週のフェーズに対応する「曜日別タスク・メニュー」を、該当する曜日の行にそのまま転記する
3. 毎日共通の「提出フォーマット（5項目）」を、全日程に共通のチェック列として追加する
4. 週末（土または日）には「週次コーチングセッション」を固定で配置する
5. 12ヶ月コースは、Week26終了時点の結果を見てから後半の分岐（上記6章）を反映する
