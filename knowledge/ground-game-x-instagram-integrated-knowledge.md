## 1. 核心：集客は接触から（地上戦もSNSも同じ）
地上戦で成果を出すのに必要なのは、突き詰めると次の3つ（裕貴さん「これがあれば地上戦は制覇できる」）。
1. **お客様になり得る人がどこにいるかを考え、そこへ行く。**
2. **できるだけ多くの人に接触する。**
3. **ヒアリング力。** 会話から相手の悩みを正確に汲み取る。

会ってからの流れ：
1. **自己紹介**：自分が何者で、どんな悩みを解決できるかを、ひと言で伝える。
2. **ヒアリングとトーク**：相手の悩みを汲み取り、そこに話題を振る。
3. **問題提起から体験へ（フッキング）**：体験に来る理由がはっきりしていれば、誘っても不自然にならない。

フックは決まった文句ではなく、**相手のニーズから組み立てる**。「パーソナルの体験を受けてみませんか」より、悩みを聞いたうえで「今キャンペーン中で、無料で受けられます」の方が自然に受け取ってもらえる。

SNSでも同じ。プロフィールが自己紹介、投稿が接触、コメント・DM・LINEがヒアリング、特典が入口になる。違いは、地上戦は**自分から接触しに行ける**こと。

（Claudeの判断）
- 「今だけ」「キャンペーン」は、期間や人数を実際に決めて守る。いつでも無料なのに「今だけ」と言うのは偽の限定になり、景品表示法の面でも危ない。
- 自分で会える人数には時間の上限がある。提携や紹介は、一人では届かない数まで接触を増やす手段にあたる。

## 2. 体験に来てもらう原則
1. **信頼は第三者から借りる。** 自分で「すごい」と言うより、整体院の先生や紹介者に勧めてもらう方が来てもらいやすい。体験への道筋は、相手によって2通りある。
   - 整体院：先生の勧めで、そのまま個別の体験へ。
   - 料理教室など：グループで一緒に体を動かして気持ちを上げ、「体を変えるには一人ひとりに合ったやり方がある」ことを理由にパーソナルを案内する。
2. **提携先にもメリットを渡す。** 契約になったら紹介料を返す（目安10〜20%、`ground-game-marketing-knowledge.md`）。相手の集客も一緒に考える。条件は相手と話し合って決める。
3. **手間をかけさせない（一番大事）。** お客様は面倒くさがり。具体的には次のとおり。
   - 軽い服装で来られるようにし、必要なものはこちらで用意する。
   - 空いている日程を先に見せ、その場で日にちを決める。
   - 「そこまでしてくれるんだ」と思ってもらえる心遣いが、離脱を防ぐ。
4. **体験は「体の現在地を確かめて、ロードマップを作る機会」として案内する。** 中心は体感。
5. **体験の後の道筋（コースかモニターか）を、先に決めてから臨む。**
6. **料金の扱い。** 体験の料金は案内には書かない。聞かれたら答え、予約を確定するときに必ず伝える。

## 3. 紹介の原則
1. 紹介は満足の結果として生まれる。成果が出るまで伴走し、満足してもらうことが前提。
2. 自分の言葉で「変わった」と話せるお客様が、紹介してくれる。だから、まず変化を聞く。
3. 紹介してほしい人の悩みを具体的に伝える（「誰か」ではなく「一人では運動が続かない方」）。
4. 紹介された人には、来る理由を用意する（例：「〇〇さんのご紹介なので、体験は無料です」）。紹介者の信用を借りられる。
5. 紹介する側にもメリットがないと、人は紹介しない。なければ作る。
6. 目指すのは、お客様に可愛がられ、信頼されるトレーナー。

## 4. 発信の原則
1. **答えではなく問いで渡す。** 「どこへ行けばいいか」を教えず、「あなたの周りだとどこにいますか？」と問いかける。自分で考えないと自走力がつかない。
2. **入口は相手の欲しい言葉、中身は本質。** 小手先で稼ぎたい人にも、自分で集客できる力という本質は響く（裕貴さん「本物になりたければ地上戦」）。
   - （Claudeの判断）タイトルは「フォロワーなしで予約が取れる」のような、相手が欲しい言葉で入る。
   - （Claudeの判断）「本物になりたければ地上戦」は、SNSを否定する言い方にしない（方針は地上戦×SNS×AI）。「まず地上戦で、自分で集客できる力をつける」という順番の話として出す。
3. **本人の経験の一言を入れ、自分の言葉で話す。** AIで作った言葉だけでは差がつかない（マーケ博士・おさるさん）。
4. **形式**
   - 1本45〜50秒、1本1メッセージ。
   - 顔を出して話す（マーケ博士のすすめ）。
   - 最後の案内は「プロフィールのLINE」の1つだけ。

## 5. リール初回4本（確定版）
### R001｜トレーナーが、SNS投稿なしで予約を増やす方法
1. トレーナーが、SNSに投稿しなくても予約を増やす方法。
2. 地域のお店と組むんです。あなたのお客様の悩みに近いお店は、どこですか？
3. いきなり提携の話はしません。知り合いのつながりから、まず先生と信頼関係を作ります。
4. 僕の場合は整体院。先生が「筋トレも受けた方がいい」と勧めてくれて、そのまま体験につながりました。
5. 大事なのは、お店にもメリットを作ること。契約になったら紹介料をお返しし、集客も一緒に考えます。
6. 提案文と案内文は、プロフィールのLINEで受け取れます。

### R002｜トレーナーが、フォロワーなしで最初の予約を取る方法
1. トレーナーが、フォロワーなしで最初の予約を取る方法。
2. お客様になりそうな人は、あなたの周りだとどこにいますか？まず自分で考えて、そこへ行く。
3. あなたは何者で、どんな悩みを解決できるか、ひと言で言えますか？それが自己紹介になります。
4. あとは相手の話をよく聞く。悩みが出たら、そこを深く聞いていく。
5. その悩みに合う体験を、「今ならキャンペーンで無料です」と伝えて、その場で日にちを決めます。
6. この3つを考えるシートは、プロフィールのLINEで受け取れます。

### R003｜トレーナーが紹介を増やすための行動3選
1. トレーナーが紹介を増やすための行動3選。
2. 一つ目、今のお客様に、始めてからの変化を聞く。自分の言葉で「変わった」と話せる人が、紹介してくれます。
3. 二つ目、紹介してほしい人の悩みを具体的に伝える。「誰か」ではなく、「一人では運動が続かない方」のように。
4. 三つ目、紹介された方だけの理由を用意する。「〇〇さんのご紹介なので、体験は無料です」。
5. 紹介者の信頼を借りられるので、来てもらいやすくなります。
6. 質問と案内の例文は、プロフィールのLINEで受け取れます。

### R004｜トレーナーが体験予約を取る方法
1. トレーナーが体験予約を取る方法。
2. お客様は、面倒なことが苦手です。手間が一つ増えるだけで、来なくなります。
3. だから、軽い服装で来られるようにして、必要なものはこちらで用意する。
4. 空いている日程を先に見せて、その場で日にちを決める。
5. 「そこまでしてくれるんだ」と思ってもらえることが、一番の離脱防止です。
6. あなたの体験の案内に、お客様の手間は残っていませんか？
7. 案内カードと予約までの返信例は、プロフィールのLINEで受け取れます。
