# 地上戦×Instagram 統合ナレッジ｜体験予約・紹介・リール制作（裕貴さんの経験×マーケ博士の型）

作成：2026-11-22（裕貴さんの依頼「伝えた内容をナレッジフォースのナレッジで解釈し、マーケ博士のナレッジと掛け合わせて、まとまったものを作って」）

## 0. この資料の位置づけ
- 何を掛け合わせたか
  - **裕貴さんの経験**：リール初回4本の聞き取り（`instagram-reel-advisor-feedback.md`12章）。整体院との提携、最初のお客様の作り方、紹介、体験予約の取り方。
  - **マーケ博士の型**：SNSビジネス構築講座の要点（`marketing-hakase-feedback.md`2〜5章）、裕貴さんへの個別の助言（`instagram-reel-advisor-feedback.md`6・7・10章）、コミュニティでの回答（`slack-community-qa-knowledge.md`）、ナレッジフォースのナレッジボックス「Instagram運用_制作ナレッジ」の制作ルール。
  - 補助：おさるさんの「SNSは出会う場所、差がつくのは一次情報」（`osaru-insights.md`9章）。
- 出典の区別：裕貴さんの経験・考え／マーケ博士の意見／Claudeが掛け合わせた解釈、を分けて書く。Claudeの解釈は「（Claudeの解釈）」と明記。
- 使う場面：トレーナー経営大学のInstagram（@yuki_trainer_keiei）の企画・台本・特典・LINE導線をつくるとき。教材や個別相談で、受講生に地上戦の体験予約の取り方を教えるとき。
- 制作の最終ルールは、ナレッジフォースのナレッジボックスの指示が優先（2026-11-21の裕貴さんの方針）。この資料は、その中身を考えるときの土台として使う。

## 1. 全体像：2つの層で、同じ原則が働く（Claudeの解釈）
裕貴さんの話とマーケ博士の型を並べると、同じ原則が2つの層で働いている。

| 層 | 流れ | 誰が誰に |
|---|---|---|
| A. 受講生（トレーナー）がお客様を集める | 接点（整体院・地域の場）→ 第三者の紹介 → 体験（体の現在地とロードマップ）→ コースかモニター → 満足 → 紹介 | トレーナー → 一般のお客様 |
| B. トレーナー経営大学が受講生を集める | リール（出会う場所）→ プロフィール → 公式LINE（キーワード）→ 特典 → 個別相談（経営の現在地とロードマップ）→ 受講するかは本人が決める | 裕貴さん → トレーナー |

- Aはリールで「教える中身」、Bはリールそのものの「導線」。
- 体験で「体の現在地とロードマップ」を作るのと、個別相談で「経営の現在地とロードマップ」を作るのは、同じ形。個別相談での「あなた専用・トレーナー売上アップロードマップ」（CLAUDE.md 4章の特典1）とも一致する。
- だから、裕貴さんが自分の導線で実際にやっていることが、そのままリールの説得力になる。

## 2. 原則の掛け合わせ

### 原則1：信頼は、第三者から借りる
- 裕貴さんの経験：自分で「すごい」と言うより、第三者（整体院の先生、紹介してくれたお客様）から「このトレーナーなら悩みに向き合ってくれる」と言ってもらうと、体験はとても取りやすい。体験の場では過去のお客様の事例を見せる。
- マーケ博士の型：プロフィールの4〜5行目に実績・権威性（2-2）。ハイライトに「お客様の声・実績」（2-3）。ストーリーズの1割は実績・お客様の声（2-10）。特典のタイトルにも実績・ストーリーを入れる（4-2）。
- 掛け合わせ（Claudeの解釈）：
  - Instagramでは、リール単体より**プロフィールとハイライトが「第三者の声」を置く場所**になる。リールで興味を持った人がプロフィールに来たとき、そこで信頼を借りられる状態にしておく。
  - リールでは「整体の先生が勧めてくれるから体験に来てもらいやすい」という**仕組みそのもの**を語る（R001の経験の一言）。
  - 守ること：事例やお客様の声は、ご本人の了承を取った実際のものだけを使う。「絶対」「必ず変わる」とは言わない（`outcome-philosophy.md`）。トレーナー経営大学の受講生の実績は、2026-11-14時点で契約5名のため、出せる実績が増えるまでは裕貴さん自身の経験と仕組みで信頼をつくる。

### 原則2：手間をかけさせない（裕貴さんいわく、一番大事）
- 裕貴さんの経験：手間は、そのまま来ない理由になる。その場で日にちまで決める。空き日程を先に見せる。相手が来たい日に来られる状態にする。持ち物・時間・やる内容を先に伝える。体験の料金は案内に書かない。
- マーケ博士の型：最後のお願いは1つに絞る。特典は「1〜2枚で今日そのまま使える量」。配り方は公式LINEのキーワード（11/22、裕貴さんへの助言）。無音でも分かる編集、1リール1メッセージ（2-5・2-7）。
- 掛け合わせ（Claudeの解釈）：
  - リールの最後の案内は「プロフィールのLINEで、〇〇と送ってください」の1つだけ。キーワードは短く、リールの題名から思い出せる言葉にする。
  - LINEでキーワードを送ったら、**待たせずすぐ特典が届く**。届いたメッセージの中で、次の一歩（個別相談の空き日程）も1回で見られるようにする。個別相談の予約は今もGoogleカレンダー連携があるので、「空き日程を先に見せる」はすでにできる土台がある。
  - 特典は2枚版（1枚目＝そのまま使う例文、2枚目＝記入欄とチェック）。2026-11-22に作成済み。

### 原則3：体験・個別相談は「売り込み」ではなく、現在地と向き合う機会として案内する
- 裕貴さんの経験：「体験に来てください」だけではハードルが高い。「体の現在地を確かめて、これからのロードマップを作る機会」として案内する。背景は、裕貴さんが健康寿命を伸ばしたいと考えていること。営業はするが、やるかどうかは相手が決める。
- マーケ博士の型：個別相談ローンチ（第3章）。営業DMでは「ご興味ありますか？」で相手のイエスを確かめてから日程に進む（2-9）。
- 掛け合わせ（Claudeの解釈）：
  - リールで教える中身（A層）：体験は「体の現在地とロードマップを作る体験」と案内する（R002の会話例・R004の体験案内カードに反映済み）。
  - 自分の導線（B層）：個別相談も「経営の現在地を確かめて、あなた専用のロードマップを作る場」と案内する。売り込みに見えず、`sales-meeting-knowledge.md`の方針（相手の現状を理解し、選択肢を一緒に考える）とも一致する。

### 原則4：体験の中心は「体感」
- 裕貴さんの経験：この仕事は体感してもらうビジネス。先の姿は想像しにくいので、事例と個別のプラン（3〜6ヶ月）で「これなら変われる」と思ってもらう。その型を先に作っておく。
- マーケ博士の型：映像の質を重視（視覚の影響が大きい、2-6）。同じ画角が3秒以上続くとスキップされやすい。人物がAIで作った写真に見えるものは避け、本人や実際の写真を使う（11/20の助言）。
- 掛け合わせ（Claudeの解釈）：リールでも「体感」に近いものを見せる。手元・紙だけでなく、実際に指導している場面や、話しているときの表情を短く入れる。注意：写真・動画素材は「トレーナー経営大学向けには入れない」という2026-11-21の方針がある一方、サムネには裕貴さん本人の写真を使っている。リール本編で指導場面を使うかは、裕貴さんの判断が必要。

### 原則5：体験の後の道筋を、先に決めてから臨む
- 裕貴さんの経験：体験の後にコースを提案するのか、モニターになってもらうのかを先に決め、案内できるロードマップを用意してから体験に臨む。
- マーケ博士の型：LINEに登録してもらえば、そのあとロードマップの案内まで続けられる（11/22の助言③）。公式LINEの初期設計（1-9）。
- 掛け合わせ（Claudeの解釈）：リールを出す前に、**LINEで特典を受け取った人が次に何を受け取り、どこで個別相談に進むか**を決めておく。これは残り作業4（LINEの準備）の中身そのもの。キーワード設定だけでなく、受け取った後の2〜3通の流れまで決めてから投稿する。

### 原則6：紹介は、満足の結果として生まれる
- 裕貴さんの経験：既存のお客様が成果を出すまで伴走し、満足してもらうのが前提。紹介する側のメリットがなければ作る。スピーカー（良いと思ったら勧めたい人）は喜ばせれば自然に紹介する。目指すのは可愛がられ、信頼されるトレーナー（あり方）。
- マーケ博士の型：お礼DM（反応してくれた人へ。押し付けない、2-9）。ストーリーズでお客様の声・価値観を出す（2-10）。
- 掛け合わせ（Claudeの解釈）：Instagramでも、反応してくれた人に丁寧に返すことが「満足→紹介」の小さな版になる。受講生が増えたら、満足した受講生の声をハイライトに置き、スピーカーになってくれる受講生を大切にする（受講生紹介制度、CLAUDE.md 1章）。

### 原則7：一次情報が差になる（AIの時代に）
- 裕貴さんの経験：上の1〜6すべてが、実際にやってきたことから出ている。
- マーケ博士の指摘：AIを使いすぎるとAIになってしまう（11/22）。当たり前の話は見られない（2-5）。
- おさるさんの指摘：投稿づくりはAIで横並びになる。差がつくのは一次情報（お客様の悩み・迷い・買わなかった理由、実際の販売データ）。
- 掛け合わせ（Claudeの解釈）：台本には必ず**裕貴さん本人の経験の一言**を入れ、自分の言葉で話す。Claudeは整理と形にするところを担う。

## 3. リール台本のつくり方（統合版の手順）
1. 誰の、どんな悩みか（トレーナー、1本1つ）。
2. 感情パターンを選ぶ（マーケ博士の10種：勉強になる／知らなかった／その手があったか／めちゃ助かる／自分もやってみたい 等）。
3. 型を選ぶ（マーケ博士の7種。初回4本は「結論→理由→解決策→CTA」と「リスト型（3選）」）。
4. タイトル：「出発条件＋欲しい結果＋方法」（ナレッジボックスのルール）。サムネと第一声を同じ文にする。
5. 本人の経験の一言を入れる（原則7）。
6. 解決策は「今日からできる形」で2〜3個（マーケ博士、コミュニティでの回答）。
7. 最後の案内は1つ（LINEのキーワード）。受け取りテストが終わるまでは「受け取れます」と言わない（ナレッジボックスのルール）。

## 4. 食い違い・確認が必要な点
- **動画の長さ（解決済み）**：初回4本の台本は60〜65秒の配分だったが、マーケ博士のコミュニティでの回答は「30〜40秒がちょうど良い（長くても50秒前後）」。2026-11-22に裕貴さんが45〜50秒で進めると決定し、読み上げ全文を作り直した（`instagram-reel-advisor-feedback.md`13章）。
- **最初のリールの案内**：マーケ博士はコミュニティで別の受講生に「最初のリールは『保存』のお願いに絞る」と答えている。一方、裕貴さんへの直接の助言（11/22）は「公式LINEのキーワードで配る」。裕貴さんへの直接の助言のほうが新しく具体的なので、そちらに従う。
- **写真・動画素材の使い方**：原則4のとおり、2026-11-21の方針（素材はトレーナー経営大学向けに入れない）と、サムネでの本人写真の使用が並んでいる。リール本編の扱いは裕貴さんの判断待ち。
- **「絶対良くなる」という言い方**：紹介者に勧めてもらうときの気持ちとしては分かるが、こちらが作る文面では使わない（原則1）。

## 5. 次のリール候補（統合して出てきたもの）
| 候補 | 中身（裕貴さんの経験） | 型（マーケ博士） |
|---|---|---|
| 紹介してもらえる人が増える「メリット」の作り方 | 紹介する側にメリットがないと紹介しない。なければ作る | 結論→理由→解決策→CTA |
| トレーナーが体験に来てもらうために減らす3つの手間 | その場で日程、空き日程の見える化、来たい日に来られる | リスト型（3選） |
| 整体院と組んで体験予約を増やす方法 | 先生が勧めてくれる仕組み、相手にもメリット、共同セミナー | 結論→理由→解決策→CTA |
| トレーナーが独立前にやっておくこと3選（R006、台本・サムネ済み） | お金・つながり・経験（月100回） | リスト型（3選） |
| 紹介されるトレーナーのあり方 | 可愛がられ、気に入られ、信頼される | 物語→結論→CTA |
