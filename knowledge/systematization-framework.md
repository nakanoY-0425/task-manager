## 2. 調査で分かったこと（事実）
1. **習慣になるまでの期間**
   - Lally ら（2010）：習慣になるまでの中央値は約66日、幅は18〜254日。水を飲むような単純な行動は早く、運動のような負担の大きい行動は時間がかかる。1回抜けても、習慣化の過程に大きな影響はなかった。
   - Singh ら（2024、系統的レビュー）：中央値59〜66日、平均106〜154日、個人差は4〜335日。「21日で習慣になる」という説には根拠がない。なお、決めた基準まで習慣化できた参加者は全体の約2割で、中央値は「習慣化できた人」の数字。
2. **「もし〜なら、〜する」と決めておく（実行意図）**
   - Gollwitzer と Sheeran（2006、94件の検証をまとめたもの）：目標の達成に中くらい〜大きめの効果（d=.65）。
   - ただし、目標そのものへの意志が弱い人には効きにくい。後の研究では効果を小さめに見積もるものもある（g=0.28〜0.34程度）。
3. **仕組みが結果を出す事業（Gerber『E-Myth』）**
   - 事業を「同じものを何度でも作れる原型（プロトタイプ）」として設計する。オーナーが毎日現場にいなくても回るように、手順を書き出し、人ではなく仕組みが結果を出す形にする。フランチャイズの考え方。
4. 既存ナレッジとの関係：Foggの行動モデル（やる気・やりやすさ・きっかけ）、アイデンティティから入る習慣づくり（James Clear）は`behavioral-design-knowledge.md`に収録済み。

## 3. 仕組み化の型（Claudeの整理・判断待ち）
業種を問わず使える5段階として整理する。トレーナー経営大学が最初の実例になる。

| 段階 | やること | トレーナー経営大学での形 |
|---|---|---|
| ① 分析 | 結果を数字に分けて、うまくいった理由・いかなかった理由を見る | 接触→悩みを聞けた→体験案内→体験→契約→継続、の数字 |
| ② 対処 | 一番詰まっている1か所に絞り、手を5〜10個出して試す | タスクの「5〜10個出す→自分で選ぶ→試す」 |
| ③ 仕組み化 | うまくいった手順を、誰がやっても同じになる形に書き出す | 台本・チェックリスト・ひな型・紹介の流れ |
| ④ 習慣化 | 決まった時間・場所・きっかけで毎回やる | 「月曜の朝に〇〇したら、接触先を3件書き出す」 |
| ⑤ 検証・更新 | 毎週数字を見て、仕組みを直す | 週1回の振り返りと面談 |

この5段階は3つの層で同じように使える。
- **受講生本人の行動**（毎日の接触、記録、振り返り）
- **受講生の事業**（集客→体験→契約→継続→紹介の流れ）
- **裕貴さんの事業**（講座の運営、受講生の伴走、他業種への横展開）

`core-philosophy.md`6章の「再現性の3段階」（①個人の再現性→②事業の再現性→③他者への再現性）と同じ並び。

## 4. Claudeの意見・指摘（そのまま賛成せず、気になる点）
1. **「仕組み化」と「自分で考える力」はぶつからない形にする。**
   仕組みにすると考えなくなる、という心配がありうる。分け方は、2026-11-24の「変えない部分と変えてよい部分」と同じ。変えない原則と、正解がある手順（価格表示・数字の計算など）は仕組みにする。考える力は、①〜⑤のサイクルそのものを毎週の習慣にして育てる。**「考えること」も仕組みで回す**、という整理。
2. **習慣になるまで約2か月、個人差が大きい。**
   6ヶ月コースの最初の3ヶ月は週1回の面談（Week1〜13）なので、ここを「習慣を入れる期間」とはっきり位置づけると調査結果とかみ合う。2か月で全員が習慣化できるわけではない（4日〜335日）ため、遅い人を「やる気がない」と見ないこと。立ち上がり遅延型（`success-maximization-framework.md`）として扱う。
3. **今のタスク表（127件）は、一回きりの提出が中心。**
   毎日・毎週くり返す行動（接触、記録、振り返り）を習慣にする仕組みが薄い。毎週同じ型で書く1枚があると、④習慣化と⑤検証が回る（保留中の「週次の数字シート」と同じもの。急がない）。
4. **タスクに「いつ・どこで・何をきっかけに」を書かせる。**
   実行意図は効果の裏づけがある、少ない手間でできる仕組み。ただし目標への意志が弱いと効きにくいので、第0章・第1章の目標設定（なぜやるのか）が先にあることが前提。
5. **気合・根性はゼロにはならない。**
   仕組みが回り始めるまでの最初の数週間は、意志の力が要る。仕組みは意志を不要にするものではなく、**意志を使う回数を減らすもの**と伝えた方が、受講生の期待とずれない。また「やり方は分かっているのに動けない」心理的ブロック型は仕組みだけでは動かないため、コーチング（第0章）と組み合わせる。
6. **人間力も一部は仕組みにできる。ただし全部ではない。**
   手間をかけさせない、先にギブする、紹介者にお礼を伝える、などは行動のチェックリストにできる。一方、第0章24節の「自分の価値を証明しようとしていない状態」は仕組みでは作れない。仕組み化は人間力の代わりではなく、**人間力を毎回出せる確率を上げるもの**。
7. **他業種の基盤にするための条件：裕貴さんがいなくても回るか。**
   E-Mythの言う原型は「オーナーがいなくても同じ結果が出る」もの。今のトレーナー経営大学は裕貴さんの面談に頼る部分が大きい。原型と言えるかは、水流さん・AI・別の講師が同じ手順で伴走して、同じような数字が出るかで確かめる。順番は、まずトレーナー経営大学で1億（2026-11-23の決定どおり）。
8. **売るときは「仕組み」ではなく「結果が安定すること」を見せる。**
   お客様は仕組みそのものより、結果が出続けることにお金を払う。「仕組み化」は中身の説明としては強いが、打ち出しの言葉としては抽象的。また「仕組みがあるから誰でも稼げる」は稼ぐ系への逆風（`course-sales-future-strategy.md`）と成果保証の禁止（`outcome-philosophy.md`）にぶつかるので使わない。

## 5. 成果が出ない型と、効く仕組み（`success-maximization-framework.md`との対応）
| 成果が出ない型 | 主な原因 | 効く仕組み |
|---|---|---|
| 時間不足型 | 動く時間がない | 決まった時間を先に確保する（実行意図）、1回の行動を小さくする |
| 経路不成立型 | お客様がいる場所に届いていない | ①分析で場所を洗い出す、接触数を毎週記録 |
| スキル不足型 | ヒアリング・提案ができない | 台本・チェックリスト、ロールプレイを毎週の型に |
| 心理的ブロック型 | 分かっていても動けない | 仕組みだけでは足りない。コーチングと組み合わせる |
| 継続率低下型 | 途中で止まる | 毎週同じ型の振り返り、仲間との進捗共有、1回抜けても戻れる設計 |
| 外部環境要因型 | 地域・家庭などの事情 | 仕組みを環境に合わせて変える（変えてよい部分） |
| 立ち上がり遅延型 | 学習中・新人 | 習慣化に時間がかかる前提で、最初の目標を小さくする |

## 7. 裕貴さんがうまくいった理由の分解（2026-11-25〜、聞き取り中）

### 本人の発言
- 一番の要因は、**独立する前に人脈をうまく作れたこと**。
- それと、**たくさんの人に応援されたこと**。

### Claudeの分解（仮説・確認待ち）
- **人脈と応援は別もの。** 人脈は「知っている人の数」、応援は「その中で実際に動いてくれる人」。知り合いの数を増やしただけでは、応援は増えない。
- **独立前に人脈を作れた＝立ち上がりの準備ができていた。** R006②「独立前に見込み客・つながりを作っておくと、融資がなくても独立直後に売上が立つ」（`instagram-reel-advisor-feedback.md`15章）と同じ話。収入がある間に人に会えるので、融資①と同じく「時間を確保している」状態でもある。
- **応援が生まれる条件（仮説）**：相手から見て「この人がうまくいくと自分もうれしい」と思える状態。
  1. 相手が先に得をしている（先にギブ）……既存の原則と同じ
  2. 何を目指しているか、相手が知っている（目標を話している）……既存ナレッジにない
  3. 進んでいる様子が見える（近況を伝えている）……既存ナレッジにない
  4. 応援しやすい（頼みごとが具体的で、相手の手間が少ない）……既存の「手間をかけさせない」と同じ
  5. 応援した結果が返ってくる（お礼と結果の報告）……紹介者への報告として一部あり

### 仕組みにするなら（Claudeの提案・判断待ち）
- 週ごとに数える行動：新しく会った人／前に会った人への再接触／先にできたこと／目標と近況を伝えた人／お礼と結果を返した人。
- 習慣になるまで約2か月かかるので、独立の3か月以上前から始めるのが筋。
- 受講生への当てはめ：パターン1（業務委託→独立志向）にはそのまま効く。パターン2（独立済み）は「今からの人脈づくり」に読み替える。パターン3（学習中・新人）は人脈も経験も薄いので、最初の目標を小さくする。

### 気になる点（Claude）
- 人柄で応援されたのか、行動で応援されたのかを分けたい。行動の部分なら教えられる。人柄の部分は第0章（人間力）の領域。
- 応援を「狙って」やると相手に見透かされる（第0章24節「価値を証明しようとしない」）。仕組みにするのは行動の数までにして、応援そのものは結果として数える。

### 確認したいこと（裕貴さんへ）
1. 独立前の人脈は、どこで、どんな人とできたか（お客様・同業・他業種・地域の人など）。どのくらいの期間をかけたか。
2. 応援してくれた人は、具体的に何をしてくれたか（お客様になった、紹介した、場所を貸した、SNSで広めた、相談に乗った等）。
3. なぜ応援されたと思うか。自分でやっていたこと（目標を話していた、近況を伝えていた、先に手伝っていた等）。

## 8. 向いている人と「お金を受け取る申し訳なさ」（2026-11-25、聞き取り中）

### 本人の発言（意味をくみ取って整理）
- トレーナーに向いているのは、人に喜ばれること、「ありがとう」と言われることが好きな人。
- ただ、そういう人ほど「お金を取るのが申し訳ない」という、根拠のないブロックを持っていることが多い。ここをうまく扱わないといけない。
- 稼ぎたいだけの人は難しい。お客様に喜ばれてうれしい、を念頭に置いてやるとうまくいく。**売上だけを追いかけると失敗する。**

### Claudeの整理
- 7章の「応援」とつながる。喜ばれるのが好きな人は、先にギブしやすく、応援されやすい。向いている理由は、性格の良さというより「接触の質が自然に高くなる」こと。
- 既存の方針と一致：セールスは売り込みではなく相手の理想の未来への選択肢を一緒に考えること（`sales-meeting-knowledge.md`）、第0章24節「価値を証明しようとしない人は、意識を相手に向けられる」。
- この「申し訳なさ」は、既存の失敗パターンでは「心理的ブロック型」（`success-maximization-framework.md` D）に入るが、具体的な中身としてはまだ記録がなかった。

### 気になる点（Claude）
1. **「売上を追わない」が「数字を見ない」にならないようにする。** 売上は結果の数字として見続ける。そのうえで、喜ばれたことを表す数字（続けてくれた人の数、紹介の数、お客様の体の変化）を先に見る数字として置くと、両方が両立する。
2. **申し訳なさは、気持ちの問題だけでなく「言い慣れていない」ことでもありうる。** 気持ちを変えるより先に、値段を口で言う回数を減らす仕組みのほうが早い：料金表を先に渡す、伝え方の台本を決める、支払いの手順を決めておく。仕組みは意志を使う回数を減らすもの（4章5）。
3. **喜ばれたい人は、値引き・無料・対応のしすぎで疲れやすい。** 無料モニターやサービスの範囲に終わりを決めておく（例：モニターは4回まで・人数を決める、LINE対応の範囲を商品に書く）。疲れると、結局お客様を喜ばせ続けられない。
4. **言い換えの候補（判断待ち）**：お金をいただくのは、相手が本気で取り組むための約束であり、こちらが一人ひとりに十分な時間をかけ続けるための条件。安くしすぎると数をこなすしかなくなり、一人ひとりに向き合えなくなる。

### 本人の答え（2026-11-25、意味をくみ取って整理）
- 申し訳なさは裕貴さんにもあった。**自信をつけ、スキルを磨くことで乗り越えた。**
- **商品設計でも変わる。** トレーニングをするだけの商品では高い単価は取れない。そこで、いくつもの方向から「武装」した：
  1. 商品の中身を厚くする（トレーニングだけでなくコーチングを入れる）
  2. トレーニングのスキルを磨く
  3. 実績をつける（「こういうお客様を、ここまで良くできた」と言える事例）
- 「この金額なら自信を持って提供できる」と思えるまで、**その金額で売り続ける**というチャレンジをした。
- **順番が大事：価値を出せてからその金額で売るのではなく、先にその金額で売り、その価値に追いつく。**

### Claudeの整理
- 第0章のBe-Do-Have（結果が出たから素晴らしいのではなく、先に在り方を決める）と同じ順番。価格を先に決めることが、自分への約束になり、成長の方向を決める。
- 「仮説を立てて行動し、結果で証明する」（教え方の核）とも一致する。価格は最初の仮説で、売れ方とお客様の変化で確かめる。
- `pricing-value-positioning-knowledge.md`の「売れないときに、すぐ値下げしない」と同じ方向。売れないときは、値段ではなく武装（中身・スキル・実績・伝え方）のどこが足りないかを見る。

### 気になる点（Claude）
1. **追いつくまでの間、お客様が損をしないようにする。** 先に高い金額で売る期間に契約したお客様は、その差を負担しうる。だから「追いつく」のは将来ではなく、その人の契約期間の中で起きる必要がある（時間を多くかける、振り返りを細かくする等）。持っていない実績を言わない、成果を約束しない（`outcome-philosophy.md`）は、この期間こそ守る。
2. **背伸びの幅を決める。** 学習中・新人型のように土台がまだ薄い人が、いきなり大きく上の金額にすると、売れない期間が長くなって自信を失いやすい。「今の自分から少し背伸び」の金額にして、追いついたら次の段に上げる、と段階にするのが安全。
3. **モニター価格とは役割を分ける。** 正規の金額は先に決めて下げない。経験や実績が足りない分は、名前・期間・人数を決めた「モニター」で埋める（3章の4回61%オフ、育成したトレーナーの無料モニターと同じ考え方）。正規の値段を下げることとは別物として教える。
4. **「追いついた」を何で判断するかを決める。** 気持ちだけで判断すると人によってぶれる。目安の候補：その金額で続けて契約が取れている、継続してくれる、紹介が出る、お客様の変化を事例として説明できる。

### 仕組みにするなら（Claudeの提案・判断待ち）
- 価格を先に決める → 毎月「武装チェック」（中身／スキル／実績／伝え方のうち、今月どれを1つ厚くしたか）→ 上の目安で「追いついたか」を見る → 追いついたら次の段の金額へ。
- 実績づくりでビフォーアフターを使うときは、成果を約束する見せ方にしない（`photo-material-catalog.md`の注意と同じ）。
