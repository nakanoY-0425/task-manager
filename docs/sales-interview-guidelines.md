# セールス面談の基本方針・ナレッジ

## 1. セールスの基本理念

セールスとは、商品を売り込むことではなく、相手の人生や現状を理解し、理想の未来に向かうための選択肢を一緒に考えることである。

そのため、最初から商品説明や契約を目的とした会話をしない。

まずは相手に興味を持ち、相手の話を聞き、安心して本音を話してもらえる関係性を築く。

**「売ろうとする」のではなく「相手を理解しようとする」ことを優先する。**

## 2. 面談の基本的な流れ

### STEP 1：生活や日常の話から始める

まずは相手の普段の生活、仕事、家族、趣味などについて自然な会話をする。

質問例：

- 普段はどんなお仕事をされているんですか？
- ちなみに、お休みの日は何をされているんですか？
- 今のお仕事は長いんですか？
- 普段はどんな生活リズムなんですか？

目的は情報収集だけではなく、相手を一人の人間として理解すること。

### STEP 2：相手の話を徹底的に聞く

自分が話すことより、相手が話す時間を大切にする。

相手の言葉を否定せず、共感しながら深掘りする。

質問例：

- そうだったんですね。それはどうしてなんですか？
- そのとき、どんなお気持ちだったんですか？
- それは大変でしたね。その後どうされたんですか？
- ちなみに、そこをもう少し詳しく聞いてもいいですか？

相手の話を聞く際には、事実だけでなく、その背景にある感情や価値観にも関心を持つ。

### STEP 3：ラポールを形成する

ラポールとは、相手が安心して本音を話せる信頼関係のこと。

相手の話を遮らず、適切な自己開示を交えながら、対等な関係性を築く。

重要なのは、無理に共感したり、相手に合わせ続けたりすることではない。

相手が「この人は自分のことを理解しようとしてくれている」と感じられること。

### STEP 4：相手の悩み・理想・過去の経験を理解する

信頼関係ができてから、現在の課題や将来の理想について深掘りする。

質問例：

- 今の生活で変えていきたいことはありますか？
- 将来的にはどんな生活を送りたいですか？
- そのために、今までどんなことに取り組まれましたか？
- うまくいかなかった理由は何だと思いますか？
- 今回取り組むとしたら、何が一番不安ですか？
- どんな環境があれば継続できそうですか？

特に、過去の失敗経験や挫折経験を理解することが重要。

同じ失敗を繰り返さないために、何が必要なのかを一緒に考える。

### STEP 5：相手が質問・相談したくなる関係をつくる

こちらから一方的に商品を説明するのではなく、相手が自分の課題を整理し、解決方法について興味を持てるようにする。

その結果として、

- 「どうしたらいいと思いますか？」
- 「何から始めればいいですか？」
- 「具体的にはどういう方法がありますか？」

といった質問が自然に生まれる状態を目指す。

ただし、相手から質問が出ないことだけを理由に、関心がないと判断しない。

必要に応じて「解決方法について、こちらからもご提案してよろしいですか？」と確認する。

### STEP 6：必要な場合にのみ商品を提案する

商品説明は、相手の課題や目標を十分に理解した後に行う。

商品の機能や特典を並べるのではなく、相手の課題に対して何が役立つのかを具体的に伝える。

提案後は、本人が納得して判断できるように、不安や疑問を確認する。

購入を急がせるのではなく、購入しない選択肢も尊重する。

## 3. 面談中に意識すること

- 自分が話すより、相手の話を聞く。
- 表面的な回答で終わらず、背景や感情まで理解する。
- 相手の過去の失敗や不安を軽視しない。
- 商品説明を急がない。
- 質問攻めにせず、自然な会話を心がける。
- 相手にとって本当に必要な商品かを見極める。
- 成約だけでなく、納得できる意思決定を大切にする。

## 4. セールスにおける最重要原則

```
信頼関係 → 本音の理解 → 課題の明確化 → 解決策の検討 → 商品提案 → 納得した意思決定
```

この順番を基本とする。

商品説明がうまくできたかではなく、相手の本音をどれだけ理解できたかを重視する。

最終的に目指すのは、「売られた」と感じる商談ではなく、「自分に必要な選択肢を一緒に考えてもらえた」と感じてもらえる商談である。

## 5. AIによる商談分析・台本作成のルール

今後、商談台本の作成、面談の振り返り、失注分析、クロージング改善を行う際は、上記の方針を基本とする。

特に以下の観点から分析する。

1. 相手が安心して話せる関係性を築けていたか。
2. 相手の話を十分に聞けていたか。
3. 現在の課題と理想の未来を理解できていたか。
4. 過去の失敗経験や不安を確認できていたか。
5. 商品提案が相手の課題と結びついていたか。
6. 購入を妨げる要因を把握できていたか。
7. 相手が納得して判断できる状態をつくれていたか。
