# fact-check.md ― 教材内の事実チェックリスト

この文書は、教材（index.html、sales-manual.md、hearing-sheet.md、talk-script.md、
objection-handling.md、closing-script.md、roi-calculator.html）の中で使われている
情報を種類ごとに分類し、営業担当者と販売元の双方が「何が確定していて、何が未確認か」を
一目で判断できるようにするためのものです。

営業担当者は、顧客の前で話す前に必ずこの表を確認し、「未確認情報」に分類された内容は
断定的に話さないでください。

---

## 1. 分類の考え方

| 区分 | 意味 | 教材内での扱い方 |
|---|---|---|
| 公的事実 | 国・自治体が公表している制度・統計 | 出典を明記し、そのまま使用可 |
| 販売元の実績 | 販売元が提示した成約率・導入社数などの内部数値 | 内部資料のみで使用。顧客向け資料には非掲載 |
| 顧客事例 | 実際の導入企業の成果事例 | 販売元から具体的な事例（社名・数値・期間）が提供されるまで使用禁止 |
| 営業上の仮定 | 説明を分かりやすくするための一般論・考え方 | 「傾向として」「一般的に」など、断定を避ける表現で使用 |
| 投資回収シミュレーション | ROI計算ツールの試算値 | 「試算であり成果を保証するものではない」と必ず併記 |
| 未確認情報 | 販売元・公的機関に確認が取れていない情報 | 教材内に記載する場合は必ず［販売元へ要確認］［出典確認が必要］を明記 |

## 4. 顧客事例

現時点で、販売元から具体的な導入企業名・数値・期間を伴う事例提供は確認されていません。

- 本教材には、架空の成功事例・架空のお客様の声は一切記載していません。
- 事例を使った説明が必要な場面では、「具体的な事例は個別にご紹介できる場合がありますので、
  一度確認いたします」と伝えるにとどめ、その場で数値を創作しないでください。
- ［販売元へ要確認：紹介可能な事例（社名・業種・地域・期間・成果指標）の有無と開示条件］

11. アフターサポートの期間・範囲
12. 紹介可能な導入企業事例（社名・業種・地域・期間・成果指標）の有無と開示条件

## 8. 禁止表現チェックリスト

以下の表現が教材内に残っていないか、公開前に必ず検索確認してください。

- 必ず補助金が出る
- 誰でも対象になる
- 実質無料になる
- 必ず儲かる
- 確実に回収できる
- 必ず単価が1.5倍になる（裏付けが確認できるまで）
- 価格競争から完全に脱却できる
- 資産価値が必ず上がる
- 全国どこでも同じ成果になる
- 今契約しないと補助金がなくなる
- 架空の成功事例／架空のお客様の声
- 根拠のない市場規模
- 未確認の提供サービスの断定的な記載
- 未確認の返金・成果保証

本教材の制作時点（2026年8月17日基準）で、上記の禁止表現は使用していません。
