価格だけで比較されるリフォーム営業から抜け出し、快適性・省エネ性能・光熱費・ 健康面・資金計画・施工品質まで含めた高付加価値提案を、自社で実践できるようにする GX営業コンテンツ

この商品が売っているのは「モノ」ではなく「提案力」です。断熱・省エネ リフォームを自社の商品として設計し、施主に価値として伝え、受注につなげるための 知識・型・伴走支援のセットです。

第3章　なぜ今GXなのか

公的事実と営業上の見解の区別について

この章では、公的機関が公表している事実（出典番号付き）と、営業担当者としての 見解・考え方を明確に分けて記載します。見解部分は「〜と考えられます」 「〜という捉え方ができます」のように、断定を避ける表現にしています。

GXとは何か（公的事実＋やさしい説明）

GXは「グリーン・トランスフォーメーション」の略で、環境に配慮しながら、 社会や経済の仕組みを変えていこうという国全体の方針です。住宅の分野では、 断熱性能を上げて冷暖房の効率を良くし、使うエネルギーやCO2（二酸化炭素）の 排出を減らす取り組みを指します。

脱炭素とは何か（やさしい説明）

脱炭素とは、CO2の排出をできるだけ減らし、実質ゼロに近づけていく取り組みの ことです。住宅は日常的にエネルギーを使う場所であるため、断熱・省エネ性能を 上げることが、脱炭素に貢献する分かりやすい手段のひとつとされています。

住宅省エネ政策との関係公的事実

国は、新築住宅の省エネ基準を段階的に引き上げるとともに、既存住宅の 省エネ改修を後押しする支援制度を用意しています1。

2025年4月の省エネ基準適合義務化公的事実

2025年4月から、新築住宅等について省エネ基準への適合が義務化されました 1。最新の制度状況は 公式サイトでの確認が前提です出典確認が必要（最新状態の再確認）。

2030年までに予定されているZEH水準への引き上げ公的事実

2030年までに、新築住宅の省エネ基準がZEH（ゼロ・エネルギー・ハウス）水準まで 引き上げられる予定であることが示されています1。 「予定」であり、確定した実施年ではない点に注意してください。

既存住宅の省エネ改修余地公的事実

国土交通省の資料では、2022年度時点で省エネ基準に適合する住宅ストックは 18％、同資料の定義に基づくと約82％が未適合とされています 2。「87％が未対応」という 数字は使用しないでください。これは確認できる出典と異なります。

今後、工務店に求められる提案力営業上の見解

以上の公的事実を踏まえると、断熱・省エネの知識を持ち、施主に分かりやすく 伝えられる会社と、従来型の工事だけを扱う会社との間で、提案の幅や差別化の面に 違いが生まれ始めていると考えられます。ただし、これは業界動向に基づく見解であり、 すべての会社に同じ成果が出ることを保証するものではありません。

第5章　施主が求めているもの

施主（住宅の持ち主）が断熱・省エネリフォームに関心を持つ背景には、次のような 不満や不安があります。効果は住宅条件・生活状況・施工内容によって異なるため、 「必ず暖かくなる」「必ず光熱費が下がる」といった保証表現は使用しません。

施主の不満・不安内容
暑さ・寒さへの不満季節による室内の温度差が大きく、快適に過ごせない
結露やカビ窓や壁の結露、それに伴うカビの発生
冷暖房効率冷暖房を使っても効きにくい、電気代がかさむ
光熱費への不安光熱費の負担増加に対する将来的な不安
健康と室内温度室温の変化が身体に与える影響への関心（ヒートショック等）
将来の住宅性能将来にわたって住み続けられる住宅性能への関心
資金面の不安リフォーム費用をどう工面するかという不安
何を選べばよいか分からない工事内容・会社・制度の情報が多く、判断基準が分からない

安さだけではなく、納得できる理由を求めていること

多くの施主は、単に安いことよりも「なぜこの工事が自分の家に必要なのか」を 納得したいと考えています。断熱・省エネの価値を分かりやすく説明できることが、 価格以外の判断材料を提供することにつながります。

第6章　価格競争から高付加価値提案へ

従来型営業のフロー

問い合わせ → 見積もり → 価格比較 → 値引き → 受注または失注

このフローでは、比較される軸が「価格」しかないため、値引き合戦になりやすく、 粗利益が下がりやすい構造になっています。

GX型営業のフロー

住まいの課題確認 → 性能診断 → 改善提案 → 快適性・省エネ効果の説明 → 補助制度・資金計画 → 施工内容 → 将来価値 → 納得による意思決定

このフローでは、価格以外にも、性能・快適性・資金計画・将来価値といった 複数の比較軸が生まれます。

表現上の注意

「価格競争から完全に脱却できる」とは表現しません。正しくは「価格以外の 比較軸を増やす」という表現を使用してください。比較軸が増えることで、 値引きだけに頼らない提案がしやすくなる、という考え方です。

第14章　よくある反論と回答

すべて「①共感 → ②本当の理由の確認 → ③事実・数字の整理 → ④相手への再質問 → ⑤判断確認」の順で構成しています。項目をクリックすると内容が開きます。

1. 「160万円は高い」
  1. 共感：率直なご意見をありがとうございます。決して小さな金額ではないと思います。
  2. 理由確認：金額そのものが高いのか、今の状況に見合うか分からないのか、どちらに近いか伺う。
  3. 事実整理：第10章の試算では、御社の粗利益水準であれば○件程度で投資額に相当する計算になる（試算であり保証ではない）。
  4. 再質問：どのくらいの期間・件数であれば納得感を持てそうか伺う。
  5. 判断確認：その基準に照らして、検討に値しそうか確認する。
2. 「本当に売上につながるのか」
  1. 共感：投資である以上、そこが一番気になるのは当然だと伝える。
  2. 理由確認：過去に期待した効果が出なかった経験があるか伺う。
  3. 事実整理：確実に売上につながるとは約束できないが、価格以外の比較軸を持てることは、価格競争に巻き込まれにくくなる可能性を高める要素と考えていることを伝える。
  4. 再質問：価格以外の比較軸を持てたら、営業にどんな変化が起きそうか伺う。
  5. 判断確認：その変化に価値を感じるなら次に進むか確認する。
3. 「補助金が終わったら使えない」
  1. 共感：制度がいつまで続くか分からない不安はもっともだと伝える。
  2. 理由確認：補助金があることを前提に考えていたか伺う。
  3. 事実整理：商品の本質は提案力そのものであり、補助金は手段のひとつに過ぎないことを伝える。制度は年度や公募状況で変わる前提であることも伝える。
  4. 再質問：補助金の有無にかかわらず、断熱・省エネの価値そのものに意味があると思うか伺う。
  5. 判断確認：制度の変化に左右されすぎず検討できそうか確認する。
4. 「自社でも調べられる」
  1. 共感：情報自体は行政の資料等でも公開されていると認める。
  2. 理由確認：自社で情報を集めて提案に落とし込む取り組みをしたことがあるか伺う。
  3. 事実整理：情報収集と、施主に伝わる形の提案・資料・トークへの体系化は別の作業であり、そこに価値があることを伝える。
  4. 再質問：自社で一から体系化するとしたら、どのくらいの時間や人手がかかりそうか伺う。
  5. 判断確認：その時間と、外部の力を借りることを比べてどちらが合っているか確認する。
5. 「忙しくて取り組めない」
  1. 共感：日々の業務で手一杯という状況を理解する。
  2. 理由確認：忙しさの中でも優先したいことか、後回しにしたいことかを伺う。
  3. 事実整理：導入は状況に合わせて進める想定であり、全てを一度に抱える必要はないことを伝える。
  4. 再質問：今取り組まなかった場合、半年後・1年後の状況はどうなっていそうか伺う。
  5. 判断確認：今始めるのと落ち着いてから始めるのと、どちらが良い結果につながりそうか確認する。
6. 「担当者がいない」
  1. 共感：専任担当者がいないと新しい取り組みは難しく感じると認める。
  2. 理由確認：担当者がいれば取り組みたい気持ちがあるか伺う。
  3. 事実整理：提供内容に営業担当者の教育が含まれること、経営者自身や兼務者が中心になって進める会社も多いことを伝える。
  4. 再質問：今の体制で一番近い立場で関わってもらえそうな人がいるか伺う。
  5. 判断確認：その人を中心に小さく始められそうか確認する。
7. 「職人がいない」
  1. 共感：施工体制がなければ実行できないという懸念は当然だと伝える。
  2. 理由確認：協力会社を新たに確保する可能性があるか、全く見込みがないかを伺う。
  3. 事実整理：施工・協力会社との連携方法も提供内容に含まれる想定だが、確保そのものは自社側の取り組みが前提であることを伝える。
  4. 再質問：施工体制を整えるとしたら、どのくらいの期間で見込めそうか伺う。
  5. 判断確認：体制が整ってから始めるか、並行して進めるか確認する（見込みが全くない場合は第13章のC判定を念頭に置く）。
8. 「地方でも需要があるのか」
  1. 共感：地域によって住宅事情が異なるのは当然の疑問だと伝える。
  2. 理由確認：地域で断熱・省エネへの関心を感じたことがあるか伺う。
  3. 事実整理：国土交通省の資料では全国で18％が適合、約82％が未適合とされているが、地域別の需要データは確認できていない旨を伝える出典確認が必要：地域別データ。
  4. 再質問：商圏で築年数が古い住宅はどのくらいの割合か伺う。
  5. 判断確認：その割合を踏まえて提案余地がありそうか確認する。
9. 「他社と比較したい」
  1. 共感：大きな投資なので比較検討は自然なことだと伝える。
  2. 理由確認：価格、内容、会社の信頼性のどれを比較したいか伺う。
  3. 事実整理：比較の際は、補助金申請代行か提案力育成のプログラムかという点、提供内容の具体性、自社に合う実行体制を前提にしているかという点を確認すると判断しやすいことを伝える。
  4. 再質問：比較にどのくらいの時間を想定しているか伺う。
  5. 判断確認：その期間の後、再度話す機会をもらえるか確認し、次回日程を確定する。
10. 「社内で相談したい」
  1. 共感：社内の意見を聞いてから判断したいのは大事なプロセスだと伝える。
  2. 理由確認：相談相手は誰か、その人が懸念しそうな点は何か伺う。
  3. 事実整理：懸念されそうな点をこの場で整理しておくと説明しやすくなることを伝える。
  4. 再質問：社内の人に特に伝えておきたいポイントはどこか伺う。
  5. 判断確認：相談結果をいつ頃までに聞けそうか確認し、次回連絡日を決める。
11. 「家族や共同経営者へ相談したい」
  1. 共感：経営に関わる大切な判断なので当然だと伝える。
  2. 理由確認：家族・共同経営者がどんな点を重視する方か伺う。
  3. 事実整理：投資額・投資回収の考え方、商品の位置づけ（補助金申請代行ではないこと）は誤解が生まれやすい点であり、説明用資料を渡せることを伝える。
  4. 再質問：可能であれば次回一緒に話を聞く機会を作れるか伺う。
  5. 判断確認：難しい場合、いつ頃までに結果を聞けそうか確認する。
12. 「今決める必要はない」
  1. 共感：今すぐ決める理由がなければそう感じるのは自然だと伝える。
  2. 理由確認：先延ばしにしたいのか、判断材料が足りないのかを伺う。
  3. 事実整理：期限を切って契約を迫るような制度上の理由はないが、確認した経営課題は時間が経つほど改善が遅れる可能性があることを伝える。
  4. 再質問：先延ばしにした場合、その課題はどう変化していきそうか伺う。
  5. 判断確認：今日の時点で、次に何を確認すれば判断できそうか整理する。
13. 「過去にコンサルで失敗した」
  1. 共感：そういった経験があると慎重になるのは当然だと伝え、詳しく伺う。
  2. 理由確認：具体的にどのような点でうまくいかなかったか伺う。
  3. 事実整理：その内容を踏まえ、今回の提供内容のどの部分が対応できる可能性があるかを伝える（実行するのは最終的に自社であるという点は変わらないことも正直に伝える）。
  4. 再質問：同じ失敗を避けるために、どんな条件が整っていれば進めやすいか伺う。
  5. 判断確認：その条件をこの場で確認できるか確認する。
14. 「成果保証がない」
  1. 共感：保証がないと不安に感じるのは当然だと伝える。
  2. 理由確認：どのような保証があれば安心できそうか伺う。
  3. 事実整理：この商品は成果を保証するものではないことを正直に伝える。保証がない代わりに、投資回収の考え方を事前に一緒に試算し、現実的な見通しを持ってもらうことを重視していることを伝える。
  4. 再質問：保証がない中で判断するとしたら、何を基準に決めるのが納得感があるか伺う。
  5. 判断確認：その基準に照らして今回の試算・内容は納得できるか確認する。
15. 「具体的な提供内容が分からない」
  1. 共感：内容が具体的に見えないと判断しづらいのは当然だと伝える。
  2. 理由確認：特にどの部分が分かりにくいか伺う。
  3. 事実整理：第8章の表を使ってカテゴリーごとに再確認する。未確認項目は「想定される項目であり、最終内容は契約前の書面で確認できる」と正直に伝える。
  4. 再質問：特に詳しく知りたい項目はどれか伺う。
  5. 判断確認：その項目について契約前に書面で確認する形で進めてよいか確認する。

第15章　クロージング

「今すぐ決めないと損をする」といった根拠のない煽りは使いません。一方で、 話を曖昧なまま終わらせず、必ず「進める」「条件を確認して進める」 「今回は見送る」のいずれかを明確にして面談を終えます。

テストクロージング

「ここまでの内容を踏まえて、率直に伺いたいのですが、今回の内容は御社に とって取り組む価値があると感じられますか。」

商品適合の確認

第13章の判定を念頭に、「この取り組みは御社に必要性が 高いと感じますか」を確認する。

意思決定者の確認

「この場でご判断いただける内容でしょうか。それとも他にご確認が必要な方が いらっしゃいますか。」

残っている不安の特定

「進めるとしたら、という前提で伺いますが、今の時点で気になる点は ありますか。」出てきた内容は第14章を使って対応する。

投資回収の確認

第10章のROIシミュレーションを再度確認し、「この試算の 前提は現実的な数字だと感じますか」を確認する。「これはあくまで試算であり、 成果を保証するものではありません」という一文を必ず伝える。

支払条件の確認

金額・税込税別・分割条件・支払方法・契約期間は販売元へ要確認。 確認できていない条件をその場で作って答えない。「詳細な支払条件については 契約書面で正式にご案内します」と伝える。

導入時期の確認

「実際に始めるとしたら、いつ頃からがよさそうですか」を確認する。

最終意思確認

「ここまでの内容を踏まえて、今日この場で進めるご判断をいただけそうですか。」

結論対応
進める契約手続きの案内に進む。次回連絡日・必要書類・支払方法を明確にして終える。
条件を確認して進める何を、誰が、いつまでに確認するのかを具体的に合意し、次回連絡日を必ず設定する。
今回は見送る見送りの理由を確認し、無理に引き止めない。今後の情報提供の可否を確認して丁寧に終える。
保留時の対応
  1. 保留の理由を具体的に確認する
  2. 該当する反論項目（第14章）で対応する
  3. 「いつまでに」「何が分かれば」判断できるかを相手の言葉で確認する
  4. 次回連絡の日時をその場で具体的に決める
  5. 双方が準備・確認すべき点を明確にする
再面談を設定する条件
  1. 次回の日時を具体的に決める（日付と時間）
  2. 可能であれば意思決定者本人の同席を依頼する
  3. 相手側が確認しておくべき点を明確にする
  4. 自社側が準備・確認しておくべき点を明確にする
  5. 再面談の議題を簡単に共有する

再面談が設定できない場合は、無理に約束を取り付けようとせず、「今回は 見送る」という判断として正直に受け止めます。

第16章　営業上の禁止表現

以下の表現は、いかなる場面でも使用しないでください。

  • 必ず補助金が出る
  • 誰でも対象になる
  • 実質無料になる
  • 必ず儲かる
  • 確実に回収できる
  • 必ず単価が1.5倍になる（裏付けとなる事例・期間・母数が確認できるまで）
  • 価格競争から完全に脱却できる
  • 資産価値が必ず上がる
  • 全国で同じ成果が出る
  • 今契約しないと損をする
  • 架空の実績
  • 架空のお客様の声
  • 未確認の提供サービスの断定的な記載
  • 未確認の成果保証
  • 未確認の返金保証

また、成約率50〜60％という数値は内部参考値です。分母・対象期間・母数が 確認できるまで、顧客向けの会話・資料のいずれにも一切使用しないでください。 営業担当者が受け取る紹介報酬・営業報酬も、いかなる場面でも顧客に伝えないで ください。

第17章　販売元へ確認する事項

営業開始前に、以下を販売元に確認し、チェックしてください。

  • 正式商品名
  • 税込価格・税別価格
  • 支払方法
  • 分割条件
  • 契約期間
  • サポート期間
  • コンテンツ一覧（最終確定版）
  • 動画本数
  • コンサル回数
  • 営業資料の具体的な内容
  • テンプレートの具体的な内容
  • 申請実務支援の範囲
  • 施工支援の範囲
  • 制度更新の頻度・方法
  • 過去の導入実績
  • 成功事例（紹介可能なものの有無）
  • 成約率50〜60％の分母・対象期間・母数
  • 解約条件
  • 返金条件
  • 成果保証の有無
  • 対応地域
  • 導入できない会社の条件
