# GX営業コンテンツ 商品理解・営業実践マニュアル

**価格以外の比較軸をつくり、高付加価値提案を実践するために**

作成日：2026年8月17日（制度情報基準日）
区分：営業担当者向け・内部資料

---

## はじめに

### この資料の目的

この資料は、約160万円のGX営業コンテンツという商品を、営業担当者が正確に理解し、
無料オンラインセミナー後の個別相談からクロージングまで、迷わず進められるようにする
ためのものです。

### 誰が使う資料か

販売元から営業代行を依頼され、無料オンラインセミナー参加者との個別相談を担当する
営業担当者が対象です。

### この資料で理解できること

1. 商品の本質
2. GX・省エネ・断熱市場について説明する方法
3. 約160万円の価値
4. 相手の経営課題の聞き出し方
5. 導入後の事業イメージ
6. 投資回収を数字で一緒に考える方法
7. 不安や反論への対応
8. 最終的な契約判断まで進める方法

### 無料セミナーと個別相談の役割の違い

| | 無料オンラインセミナー | 個別相談 |
|---|---|---|
| 目的 | 商品・市場への関心を持ってもらう | 相手の状況を理解し、合理的な判断を後押しする |
| 内容 | 一般的な情報提供 | 個別の経営課題に合わせた提案 |
| ゴール | 個別相談への申込み | 契約判断（進める／条件確認／見送る） |

### 営業担当者に求められる役割

- 商品を正しく説明すること（誇張しない、断定しない）
- 相手の経営課題を正確に聞き出すこと
- 数字に基づいて投資回収を一緒に考えること
- 不安や反論に、誠実に向き合うこと
- 相手が自分で納得して判断できるように導くこと

### 相手に合わない場合は無理に販売しない方針

この商品は、すべての会社に合うわけではありません。第13章の適合度判定でC評価と
なった見込み客には、無理に販売しないことを推奨します。無理な販売は、短期的な成約より
長期的な信頼を損ないます。

## 第2章　この商品は何を売っているのか

### 商品の本質

この商品が売っているのは「モノ」ではなく「提案力」です。断熱・省エネリフォームを
自社の商品として設計し、施主に価値として伝え、受注につなげるための知識・型・
伴走支援のセットです。

### 補助金申請代行との違い

| 項目 | 補助金申請代行サービス | このGX営業コンテンツ |
|---|---|---|
| 提供するもの | 申請書類の作成・提出代行 | 高付加価値提案を自社で実践する力・資料・伴走支援 |
| ゴール | 補助金を受け取ること | 提案力を身につけ、受注につなげること |
| 補助金の位置づけ | 商品そのもの | 施主の負担を抑える手段のひとつ |
| 継続性 | 制度が終われば価値も終わりやすい | 提案の考え方・スキルは制度が変わっても会社に残る |

### コンサルティングとの違い

一般的な経営コンサルティングが「会社全体の経営課題」を扱うのに対し、このGX営業
コンテンツは「断熱・省エネという特定領域の営業力強化」に特化しています。対象が
明確な分、成果につながる行動に落とし込みやすい設計になっています
（コンサルティングとの厳密な違い・棲み分けの説明は［販売元へ要確認］）。

### 単なる動画教材との違い

動画を見て終わりではなく、個別コンサルティングや導入サポートを通じて、自社の
状況に合わせて実践まで伴走する点が異なります（個別コンサルティングの具体的な
回数・頻度は［販売元へ要確認］）。

### 導入会社に残るもの

- 断熱・省エネを軸にした自社の高付加価値商品
- 施主への提案トーク・資料・見積もりの型
- 営業担当者の提案力
- 過去客への再提案の仕組み

### 160万円で取得するべき価値

価格そのものではなく、「価格競争に巻き込まれない提案軸を、自社の力として持てる
こと」が160万円の価値です。詳細な提供内容は第8章の表を参照してください。

### 成果を出すために導入会社側が行うこと

- 営業担当者・施工体制など、実行するための最低限の体制を用意すること
- 学んだ内容を、実際の施主提案で使ってみること

## 第3章　なぜ今GXなのか

### 公的事実と営業上の見解の区別について

この章では、公的機関が公表している事実（出典番号付き）と、営業担当者としての
見解・考え方を明確に分けて記載します。見解部分は「〜と考えられます」「〜という
捉え方ができます」のように、断定を避ける表現にしています。

### GXとは何か（公的事実＋やさしい説明）

GXは「グリーン・トランスフォーメーション」の略で、環境に配慮しながら、社会や
経済の仕組みを変えていこうという国全体の方針です。住宅の分野では、断熱性能を
上げて冷暖房の効率を良くし、使うエネルギーやCO2（二酸化炭素）の排出を減らす
取り組みを指します。

### 脱炭素とは何か（やさしい説明）

脱炭素とは、CO2の排出をできるだけ減らし、実質ゼロに近づけていく取り組みのことです。
住宅は日常的にエネルギーを使う場所であるため、断熱・省エネ性能を上げることが、
脱炭素に貢献する分かりやすい手段のひとつとされています。

### 住宅省エネ政策との関係（公的事実）

国は、新築住宅の省エネ基準を段階的に引き上げるとともに、既存住宅の省エネ改修を
後押しする支援制度を用意しています［注1］。

### 2025年4月の省エネ基準適合義務化（公的事実）

2025年4月から、新築住宅等について省エネ基準への適合が義務化されました［注1］。
最新の制度状況は公式サイトでの確認が前提です［出典確認が必要（最新状態の再確認）］。

### 2030年までに予定されているZEH水準への引き上げ（公的事実）

2030年までに、新築住宅の省エネ基準がZEH（ゼロ・エネルギー・ハウス）水準まで
引き上げられる予定であることが示されています［注1］。「予定」であり、確定した
実施年ではない点に注意してください。

### 既存住宅の省エネ改修余地（公的事実）

国土交通省の資料では、2022年度時点で省エネ基準に適合する住宅ストックは18％、
同資料の定義に基づくと約82％が未適合とされています［注2］。「87％が未対応」という
数字は使用しないでください。これは確認できる出典と異なります。

### 国の補助制度（公的事実・制度名のみ確認）

- 住宅省エネ2026キャンペーン［注3］
- 先進的窓リノベ2026［注4］
- 住宅の省エネ・脱炭素に関する情報ページ［注5］

いずれも制度名の存在のみ確認できています。対象工事・補助額・申請条件・実施期間の
詳細は本資料作成時点で確認できておらず、［出典確認が必要］です。個別相談では
「最新の金額・条件は公式サイトまたは制度事務局で必ずご確認ください」と必ず添えて
ください。

### 今後、工務店に求められる提案力（営業上の見解）

以上の公的事実を踏まえると、断熱・省エネの知識を持ち、施主に分かりやすく伝えられる
会社と、従来型の工事だけを扱う会社との間で、提案の幅や差別化の面に違いが生まれ始めて
いると考えられます。ただし、これは業界動向に基づく見解であり、すべての会社に
同じ成果が出ることを保証するものではありません。

## 第4章　工務店・リフォーム会社が直面している問題

### 全体像

| 課題 | 内容 |
|---|---|
| 新築市場の変化 | 新築着工数が減少傾向にあり、新築中心だった会社がリフォーム市場に参入している |
| リフォーム市場の競争 | 参入が増えたことで、リフォーム市場の競争が激しくなっている |
| 資材価格の上昇 | 資材コストの上昇が、工事コストと利益を圧迫している |
| 人手不足 | 職人・現場監督などの人手不足が、供給力に影響している |
| 相見積もり | 施主が複数社に見積もりを依頼することが一般化している |
| 値引き | 受注のために値引きが常態化しやすい環境がある |
| 粗利益低下 | 値引きの結果、粗利益が下がりやすい状況が生まれている |
| 広告費上昇 | 集客競争の激化により、広告費が上昇傾向にある |
| 過去客を活用できていない | 過去に施工した顧客への再提案が行われず、関係が休眠状態になりやすい |

（各数値の業界全体の統計データは本資料作成時点では確認できておらず
［出典確認が必要］。上記は一般的な傾向としての整理です。）

### 好調な会社にも将来対策が必要な理由

現在受注が好調な会社であっても、上記の構造的な変化は業界全体に及ぶため、
数年後には同じ競争環境に直面する可能性があります。好調なうちに新しい収益の柱を
準備しておくことは、経営判断として合理的です。

### この商品の位置づけ

- 苦しい会社にとっては、価格競争から抜け出す一つの道
- 好調な会社にとっては、5年後・10年後を見据えた次の収益の柱

「今動かなければ必ず倒産する」といった過剰な表現は使用しません。あくまで
経営判断のための材料として、事実を提示します。

## 第5章　施主が求めているもの

施主（住宅の持ち主）が断熱・省エネリフォームに関心を持つ背景には、次のような
不満や不安があります。効果は住宅条件・生活状況・施工内容によって異なるため、
「必ず暖かくなる」「必ず光熱費が下がる」といった保証表現は使用しません。

| 施主の不満・不安 | 内容 |
|---|---|
| 暑さ・寒さへの不満 | 季節による室内の温度差が大きく、快適に過ごせない |
| 結露やカビ | 窓や壁の結露、それに伴うカビの発生 |
| 冷暖房効率 | 冷暖房を使っても効きにくい、電気代がかさむ |
| 光熱費への不安 | 光熱費の負担増加に対する将来的な不安 |
| 健康と室内温度 | 室温の変化が身体に与える影響への関心（ヒートショック等） |
| 将来の住宅性能 | 将来にわたって住み続けられる住宅性能への関心 |
| 資金面の不安 | リフォーム費用をどう工面するかという不安 |
| 何を選べばよいか分からない | 工事内容・会社・制度の情報が多く、判断基準が分からない |

### 安さだけではなく、納得できる理由を求めていること

多くの施主は、単に安いことよりも「なぜこの工事が自分の家に必要なのか」を
納得したいと考えています。断熱・省エネの価値を分かりやすく説明できることが、
価格以外の判断材料を提供することにつながります。

## 第6章　価格競争から高付加価値提案へ

### 従来型営業のフロー

問い合わせ　→　見積もり　→　価格比較　→　値引き　→　受注または失注

このフローでは、比較される軸が「価格」しかないため、値引き合戦になりやすく、
粗利益が下がりやすい構造になっています。

### GX型営業のフロー

住まいの課題確認　→　性能診断　→　改善提案　→　快適性・省エネ効果の説明　→
補助制度・資金計画　→　施工内容　→　将来価値　→　納得による意思決定

このフローでは、価格以外にも、性能・快適性・資金計画・将来価値といった
複数の比較軸が生まれます。

### 表現上の注意

「価格競争から完全に脱却できる」とは表現しません。正しくは「価格以外の
比較軸を増やす」という表現を使用してください。比較軸が増えることで、
値引きだけに頼らない提案がしやすくなる、という考え方です。

## 第7章　導入会社にとっての事業価値

| 価値 | 内容 |
|---|---|
| 高付加価値商品の設計 | 断熱・省エネを軸にした自社商品を持てる |
| 提案範囲の拡大 | 一件あたりの提案範囲を広げられる |
| 受注単価向上の可能性 | 高付加価値化により、受注単価の向上を目指せる |
| 粗利益向上の可能性 | 値引きに頼らない提案により、粗利益の向上を目指せる |
| 過去客への再提案 | 過去に施工した顧客への新しい提案材料になる |
| 追加工事 | 提案範囲の拡大が、追加工事につながる可能性がある |
| 紹介 | 満足度の高い提案が、紹介につながる可能性がある |
| 営業担当者の育成 | 提案力のある営業担当者を育成できる |
| GXに詳しい会社としての差別化 | 制度・市場に詳しい会社として認知される可能性がある |
| 新しい収益の柱 | 断熱・省エネを軸にした新しい収益の柱を作れる |

### 表現上の注意（重要）

「必ず儲かる」「必ず単価が1.5倍になる」という表現は使用しません。受注単価の
変化について具体的な倍率を伝える場合は、販売元が確認可能な事例・期間・母数を
提示できた場合に限ります。それまでは「高付加価値化により、受注単価や粗利益の
向上を目指す」という表現に統一してください（裏付けデータの有無は
［販売元へ要確認］）。

## 第10章　投資回収の考え方

約160万円を「高い・安い」だけで判断するのではなく、「何件受注すれば回収の
目安になるか」という視点で考える章です。すべて試算であり、成果を保証するもの
ではありません。

### 計算式

```
回収必要件数　＝　導入費用 ÷ 1件あたり追加粗利益
回収月数　　　＝　導入費用 ÷ 月間追加粗利益
```

### 初期事例（導入費用1,600,000円の場合）

| 1件あたり追加粗利益 | 回収に必要な件数（目安） |
|---|---|
| 200,000円 | 8件 |
| 300,000円 | 6件（端数切り上げ） |
| 400,000円 | 4件 |

### ROIシミュレーション（本文中に埋め込み）

index.html では、この章の中に、以下の項目をブラウザ上で自由に変更できる
ROI計算機を実装しています。document-source.md では計算式のみ記載します。

**入力項目**：導入費用／月間提案件数／成約率／1件あたり追加売上／
1件あたり追加粗利益

**自動計算される項目**：

```
月間成約件数　＝　月間提案件数 × 成約率(％) ÷ 100
月間追加売上　＝　月間成約件数 × 1件あたり追加売上
月間追加粗利益　＝　月間成約件数 × 1件あたり追加粗利益
回収必要件数　＝　導入費用 ÷ 1件あたり追加粗利益（端数切り上げ）
回収月数　　　＝　回収必要件数 ÷ 月間成約件数
```

すべて試算であり、成果を保証するものではありません。個別相談の場では、この
前提を必ず口頭でも伝えてください。

## 第11章　個別相談の進め方

個別相談（60〜90分想定）を15の段階に分けて説明します。各段階に「目的」
「話す内容」「質問」「確認ポイント」「次へ進む条件」を付けています。

### 1. 挨拶

- **目的**：信頼関係の入り口を作る
- **話す内容**：自己紹介、セミナー参加への感謝
- **質問**：「セミナーの中で、特に印象に残った部分はありましたか」
- **確認ポイント**：相手の関心事項
- **次へ進む条件**：一通りの会話が成立すること

### 2. 面談目的の共有

- **目的**：本日の進め方について合意を取る
- **話す内容**：「まず御社の状況をお伺いした上で、この取り組みが御社に合うかを
  一緒に確認したい」という趣旨の共有
- **質問**：「このような進め方でよろしいでしょうか」
- **確認ポイント**：相手の同意
- **次へ進む条件**：進め方への合意

### 3. 今日のゴール確認

- **目的**：本日中の意思決定の可能性を確認する
- **話す内容**：「もし今日のお話で意味があると感じていただけたら、この場で
  次のステップに進むご判断は可能でしょうか」
- **質問**：「それとも、社内で確認が必要なプロセスがありますか」
- **確認ポイント**：意思決定者かどうか、社内プロセスの有無
- **次へ進む条件**：どちらのケースかを把握できたこと（無理に即決を迫らない）

### 4. 現状ヒアリング

- **目的**：相手の会社の現状を理解する
- **話す内容**：「まず御社の今の状況を教えてください」
- **質問**：第12章の質問1〜14
- **確認ポイント**：売上構成、単価、粗利益、体制
- **次へ進む条件**：現状の全体像が把握できたこと

### 5. 課題整理

- **目的**：聞き取った内容を整理し、認識をすり合わせる
- **話す内容**：ヒアリング内容の要約
- **質問**：「今お伝えした理解で合っていますか」
- **確認ポイント**：認識のズレがないか
- **次へ進む条件**：相手の合意が得られること

### 6. 理想の状態確認

- **目的**：将来のありたい姿を聞く
- **話す内容**：「1年後・3年後、会社をどういう状態にしたいですか」
- **質問**：第12章の質問15・16
- **確認ポイント**：将来像の具体性
- **次へ進む条件**：将来像が言語化できること

### 7. 現状と理想の差を確認

- **目的**：ギャップを本人の言葉で認識してもらう
- **話す内容**：「現状は○○、目指す姿は○○。その差は主に△△にあるように思います」
- **質問**：「このギャップについて、どう感じられますか」
- **確認ポイント**：ギャップへの納得感
- **次へ進む条件**：ギャップの存在に同意すること

### 8. GX市場の説明

- **目的**：業界の変化を事実ベースで共有する
- **話す内容**：第3章・第4章の内容を簡潔に説明
- **質問**：「このあたりの流れは、普段の営業活動の中で実感されますか」
- **確認ポイント**：実感の有無
- **次へ進む条件**：市場変化への理解

### 9. 商品説明

- **目的**：商品の本質を正しく伝える
- **話す内容**：第1章・第2章の内容（補助金申請代行ではないことを明確に）
- **質問**：「ここまでで、この商品が何を目的としているか、イメージは湧きましたか」
- **確認ポイント**：商品理解の正確さ
- **次へ進む条件**：誤解なく理解されていること

### 10. 提供内容

- **目的**：160万円の中身を具体的に伝える
- **話す内容**：第8章の表を使った説明
- **質問**：特になし（説明中心）
- **確認ポイント**：未確認項目を断定していないか
- **次へ進む条件**：内容への理解

### 11. 投資回収

- **目的**：数字で投資判断を一緒に考える
- **話す内容**：第10章のROIシミュレーションを画面共有しながら実施
- **質問**：「この件数感は、現実的だと感じますか」
- **確認ポイント**：前提数値の妥当性
- **次へ進む条件**：試算結果への納得感

### 12. 適合確認

- **目的**：本当に合う相手かを見極める
- **話す内容**：第13章の適合度判定を念頭に置いた確認
- **質問**：「率直に、この取り組みは御社に必要性が高いと感じますか」
- **確認ポイント**：A・B・Cいずれの判定になりそうか
- **次へ進む条件**：正直な手応えが得られること

### 13. 不安確認

- **目的**：残っている懸念を洗い出す
- **話す内容**：「気になる点があれば、遠慮なく聞かせてください」
- **質問**：特になし（傾聴）
- **確認ポイント**：出てきた懸念の内容
- **次へ進む条件**：懸念に対応できること（第14章を使用）

### 14. 条件説明

- **目的**：契約条件を正確に伝える
- **話す内容**：料金・支払条件・契約期間（［販売元へ要確認］の情報は断定しない）
- **質問**：特になし
- **確認ポイント**：正確な情報のみ伝えているか
- **次へ進む条件**：条件への理解

### 15. 意思決定

- **目的**：面談を曖昧に終わらせない
- **話す内容**：第15章のクロージング台本を使用
- **質問**：「今日この場で進めるご判断はいただけそうですか」
- **確認ポイント**：進める／条件確認して進める／見送る、のいずれか
- **次へ進む条件**：3つの結論のいずれかが明確になること

## 第12章　ヒアリング質問集

各質問に「質問の意図」「回答から判断すること」「深掘り質問」
「商品説明へのつなぎ方」を付けています。

### 1. 現在の売上構成

- **意図**：事業の重心を知る
- **判断すること**：リフォームの比重
- **深掘り質問**：「その中でリフォームはどのくらいの割合ですか」
- **つなぎ方**：比重が低ければ「これから展開する分野」として、高ければ
  「すでに競争環境にある分野」として第4章につなげる

### 2. 新築とリフォームの比率

- **意図**：市場変化の実感の有無を知る
- **判断すること**：比率の変化傾向
- **深掘り質問**：「ここ数年で、その比率はどう変わっていますか」
- **つなぎ方**：変化を実感していれば、第3章・第4章の説明への納得感が高い

### 3. 平均受注単価

- **意図**：現在の提案がどの価格帯で成立しているか
- **判断すること**：単価水準
- **深掘り質問**：「その単価は、ここ数年で上がっていますか、下がっていますか」
- **つなぎ方**：第10章のROIシミュレーションの初期値に使う

### 4. 平均粗利益

- **意図**：収益性の実態を知る
- **判断すること**：粗利益の傾向
- **深掘り質問**：「粗利益が下がってきているとしたら、主な理由は何だと思いますか」
- **つなぎ方**：値引きが理由であれば第6章（比較軸の話）につなげる

### 5. 年間施工件数

- **意図**：事業規模と母数を知る
- **判断すること**：提案を乗せられる件数
- **深掘り質問**：「そのうち、リフォームは何件くらいですか」
- **つなぎ方**：第10章のROIシミュレーションの前提に使う

### 6. 値引き頻度

- **意図**：価格でしか差別化できていないかを知る
- **判断すること**：値引きの常態化度合い
- **深掘り質問**：「値引きをする場合、どのくらいの幅が多いですか」
- **つなぎ方**：常態化していれば第6章の比較軸の話につなげる

### 7. 相見積もりの失注状況

- **意図**：価格競争が実際に起きているかを知る
- **判断すること**：失注理由に価格がどれだけ関係しているか
- **深掘り質問**：「失注する場合、価格以外の理由はありますか」
- **つなぎ方**：価格理由が多ければ第6章・第7章につなげる

### 8. 過去顧客数

- **意図**：再提案できる母数があるかを知る
- **判断すること**：過去客を活用した展開余地
- **深掘り質問**：「累計でどのくらいのお客様に施工されましたか」
- **つなぎ方**：多ければ第7章（過去客への再提案）につなげる

### 9. 既存顧客への再提案状況

- **意図**：過去客との関係が継続しているかを知る
- **判断すること**：休眠状態かどうか
- **深掘り質問**：「その後も連絡や提案を続けていますか」
- **つなぎ方**：休眠が多ければ、再提案の仕組みづくりの必要性につなげる

### 10. GX提案経験

- **意図**：知識・経験の土台があるかを知る
- **判断すること**：ゼロからのスタートか、土台があるか
- **深掘り質問**：「これまでに断熱・省エネの提案をされたことはありますか」
- **つなぎ方**：未経験なら第3章の基礎知識から丁寧に説明する

### 11. 補助制度への対応状況

- **意図**：制度活用の実務経験を知る
- **判断すること**：制度理解の深さ
- **深掘り質問**：「補助金を使った工事に対応された経験はありますか」
- **つなぎ方**：経験がなければ第2章（補助金申請代行との違い）を丁寧に説明する

### 12. 営業担当者数

- **意図**：提案を実行する人員がいるかを知る
- **判断すること**：教育の前提
- **深掘り質問**：「営業を担当されている方は何名いらっしゃいますか」
- **つなぎ方**：少なければ第8章の「営業研修」の説明を重点的に行う

### 13. 施工体制

- **意図**：受注後に実際に施工できるかを知る
- **判断すること**：向いている会社かどうかの重要な判断材料
- **深掘り質問**：「断熱・省エネ工事に対応できる職人や協力会社はいますか」
- **つなぎ方**：全くなければ第13章のC判定の可能性を念頭に置く

### 14. 事務担当者

- **意図**：資金計画・申請実務を回せる体制かを知る
- **判断すること**：導入後の運用負荷
- **深掘り質問**：「見積もりや書類対応を担当する方はいますか」
- **つなぎ方**：いなければ導入後の運用負荷について正直に伝える

### 15. 今後作りたい事業

- **意図**：GX・断熱が経営者の選択肢に入っているかを知る
- **判断すること**：商品への納得感の土台
- **深掘り質問**：「新しい売上の柱として、どんな分野を考えていますか」
- **つなぎ方**：GXが候補にあれば商品説明への納得感が高い

### 16. 1年後・3年後の目標

- **意図**：短期・中期の経営目標を知る
- **判断すること**：商品が提供する価値との一致度
- **深掘り質問**：「その目標に向けて、今何が一番の課題ですか」
- **つなぎ方**：目標と商品価値の一致点を明示的に伝える

### 17. 意思決定者

- **意図**：この場で判断できる相手かを知る
- **判断すること**：即決可能かどうか
- **深掘り質問**：「ご自身お一人で決められますか、他にご確認が必要な方は
  いますか」
- **つなぎ方**：別にいる場合は第15章の「再面談を設定する条件」につなげる

### 18. 導入時期

- **意図**：検討の現実性を知る
- **判断すること**：時期の具体性
- **深掘り質問**：「導入するとしたら、いつ頃から始めたいですか」
- **つなぎ方**：具体的な時期があれば、そこから逆算して次のステップを提案する

### 19. 予算

- **意図**：160万円が現実的なレンジかを知る
- **判断すること**：予算感との乖離
- **深掘り質問**：「このような投資に、社内で確保できる予算感はどのくらいですか」
- **つなぎ方**：大きく乖離していれば無理に契約を勧めない

### 20. 最大の不安

- **意図**：最大の不安・反論の種を知る
- **判断すること**：クロージング前に解消すべき論点
- **深掘り質問**：「今の時点で、一番引っかかっている点は何ですか」
- **つなぎ方**：第14章の該当項目を使って対応する

## 第13章　向いている会社・向いていない会社

ヒアリング終了後、以下の10項目を確認し、A・B・Cの3段階で適合度を判定します。

### 確認項目

| 項目 | 確認内容 |
|---|---|
| 顧客基盤 | 過去客・既存客の数と関係の継続度 |
| 経営者の意欲 | 経営者自身がGX・断熱に前向きか |
| 営業担当者 | 提案を実行する人員がいるか |
| 施工体制 | 断熱・省エネ工事に対応できる職人・協力会社がいるか |
| 事務体制 | 見積もり・書類対応ができる人員がいるか |
| 投資余力 | 160万円という投資に対する予算的な余力 |
| 実行時間 | 学習・実践に充てられる時間があるか |
| 過去客 | 再提案できる過去客が一定数いるか |
| 既存事業との相性 | 現在の事業内容と断熱・省エネ提案の相性 |
| 意思決定時期 | 導入時期が具体的に想定できているか |

### A（強く適合）

上記10項目の大半を満たし、特に「施工体制」「意思決定者の明確さ」
「経営者の意欲」がそろっている状態。個別相談内でのクロージングに進んで
問題ない対象です。

### B（条件付きで適合）

課題意識はあるが、体制（営業・施工・事務のいずれか）または意思決定プロセスに
不足がある状態。不足している条件を明確にした上で、再面談または条件確認の
ステップに進めてください。

### C（現時点では適合しない）

施工体制の確保が全く見込めない、補助金の受給のみが目的で提案力の獲得に
関心がない、予算感が160万円と大きく乖離している、事業の方向性がGX・断熱と
明確に異なる、のいずれかに該当する状態です。

この場合は、正直に状況を伝えてください。無理な契約は、双方にとって
良い結果になりません。

## 第14章　よくある反論と回答

すべて「①共感 → ②本当の理由の確認 → ③事実・数字の整理 → ④相手への再質問 →
⑤判断確認」の順で構成しています。

### 1. 「160万円は高い」

1. 共感：率直なご意見をありがとうございます。決して小さな金額ではないと思います。
2. 理由確認：金額そのものが高いのか、今の状況に見合うか分からないのか、
   どちらに近いか伺う。
3. 事実整理：第10章の試算では、御社の粗利益水準であれば○件程度で投資額に
   相当する計算になる（試算であり保証ではない）。
4. 再質問：どのくらいの期間・件数であれば納得感を持てそうか伺う。
5. 判断確認：その基準に照らして、検討に値しそうか確認する。

### 2. 「本当に売上につながるのか」

1. 共感：投資である以上、そこが一番気になるのは当然だと伝える。
2. 理由確認：過去に期待した効果が出なかった経験があるか伺う。
3. 事実整理：確実に売上につながるとは約束できないが、価格以外の比較軸を
   持てることは、価格競争に巻き込まれにくくなる可能性を高める要素と考えている
   ことを伝える。
4. 再質問：価格以外の比較軸を持てたら、営業にどんな変化が起きそうか伺う。
5. 判断確認：その変化に価値を感じるなら次に進むか確認する。

### 3. 「補助金が終わったら使えない」

1. 共感：制度がいつまで続くか分からない不安はもっともだと伝える。
2. 理由確認：補助金があることを前提に考えていたか伺う。
3. 事実整理：商品の本質は提案力そのものであり、補助金は手段のひとつに
   過ぎないことを伝える。制度は年度や公募状況で変わる前提であることも伝える。
4. 再質問：補助金の有無にかかわらず、断熱・省エネの価値そのものに意味が
   あると思うか伺う。
5. 判断確認：制度の変化に左右されすぎず検討できそうか確認する。

### 4. 「自社でも調べられる」

1. 共感：情報自体は行政の資料等でも公開されていると認める。
2. 理由確認：自社で情報を集めて提案に落とし込む取り組みをしたことがあるか
   伺う。
3. 事実整理：情報収集と、施主に伝わる形の提案・資料・トークへの体系化は
   別の作業であり、そこに価値があることを伝える。
4. 再質問：自社で一から体系化するとしたら、どのくらいの時間や人手が
   かかりそうか伺う。
5. 判断確認：その時間と、外部の力を借りることを比べてどちらが合っているか
   確認する。

### 5. 「忙しくて取り組めない」

1. 共感：日々の業務で手一杯という状況を理解する。
2. 理由確認：忙しさの中でも優先したいことか、後回しにしたいことかを伺う。
3. 事実整理：導入は状況に合わせて進める想定であり、全てを一度に抱える
   必要はないことを伝える。
4. 再質問：今取り組まなかった場合、半年後・1年後の状況はどうなっていそうか
   伺う。
5. 判断確認：今始めるのと落ち着いてから始めるのと、どちらが良い結果に
   つながりそうか確認する。

### 6. 「担当者がいない」

1. 共感：専任担当者がいないと新しい取り組みは難しく感じると認める。
2. 理由確認：担当者がいれば取り組みたい気持ちがあるか伺う。
3. 事実整理：提供内容に営業担当者の教育が含まれること、経営者自身や兼務者が
   中心になって進める会社も多いことを伝える。
4. 再質問：今の体制で一番近い立場で関わってもらえそうな人がいるか伺う。
5. 判断確認：その人を中心に小さく始められそうか確認する。

### 7. 「職人がいない」

1. 共感：施工体制がなければ実行できないという懸念は当然だと伝える。
2. 理由確認：協力会社を新たに確保する可能性があるか、全く見込みがないかを
   伺う。
3. 事実整理：施工・協力会社との連携方法も提供内容に含まれる想定だが、
   確保そのものは自社側の取り組みが前提であることを伝える。
4. 再質問：施工体制を整えるとしたら、どのくらいの期間で見込めそうか伺う。
5. 判断確認：体制が整ってから始めるか、並行して進めるか確認する（見込みが
   全くない場合は第13章のC判定を念頭に置く）。

### 8. 「地方でも需要があるのか」

1. 共感：地域によって住宅事情が異なるのは当然の疑問だと伝える。
2. 理由確認：地域で断熱・省エネへの関心を感じたことがあるか伺う。
3. 事実整理：国土交通省の資料では全国で18％が適合、約82％が未適合とされて
   いるが、地域別の需要データは確認できていない旨を伝える
   ［出典確認が必要：地域別データ］。
4. 再質問：商圏で築年数が古い住宅はどのくらいの割合か伺う。
5. 判断確認：その割合を踏まえて提案余地がありそうか確認する。

### 9. 「他社と比較したい」

1. 共感：大きな投資なので比較検討は自然なことだと伝える。
2. 理由確認：価格、内容、会社の信頼性のどれを比較したいか伺う。
3. 事実整理：比較の際は、補助金申請代行か提案力育成のプログラムかという点、
   提供内容の具体性、自社に合う実行体制を前提にしているかという点を
   確認すると判断しやすいことを伝える。
4. 再質問：比較にどのくらいの時間を想定しているか伺う。
5. 判断確認：その期間の後、再度話す機会をもらえるか確認し、次回日程を
   確定する。

### 10. 「社内で相談したい」

1. 共感：社内の意見を聞いてから判断したいのは大事なプロセスだと伝える。
2. 理由確認：相談相手は誰か、その人が懸念しそうな点は何か伺う。
3. 事実整理：懸念されそうな点をこの場で整理しておくと説明しやすくなることを
   伝える。
4. 再質問：社内の人に特に伝えておきたいポイントはどこか伺う。
5. 判断確認：相談結果をいつ頃までに聞けそうか確認し、次回連絡日を決める。

### 11. 「家族や共同経営者へ相談したい」

1. 共感：経営に関わる大切な判断なので当然だと伝える。
2. 理由確認：家族・共同経営者がどんな点を重視する方か伺う。
3. 事実整理：投資額・投資回収の考え方、商品の位置づけ（補助金申請代行では
   ないこと）は誤解が生まれやすい点であり、説明用資料を渡せることを伝える。
4. 再質問：可能であれば次回一緒に話を聞く機会を作れるか伺う。
5. 判断確認：難しい場合、いつ頃までに結果を聞けそうか確認する。

### 12. 「今決める必要はない」

1. 共感：今すぐ決める理由がなければそう感じるのは自然だと伝える。
2. 理由確認：先延ばしにしたいのか、判断材料が足りないのかを伺う。
3. 事実整理：期限を切って契約を迫るような制度上の理由はないが、確認した
   経営課題は時間が経つほど改善が遅れる可能性があることを伝える。
4. 再質問：先延ばしにした場合、その課題はどう変化していきそうか伺う。
5. 判断確認：今日の時点で、次に何を確認すれば判断できそうか整理する。

### 13. 「過去にコンサルで失敗した」

1. 共感：そういった経験があると慎重になるのは当然だと伝え、詳しく伺う。
2. 理由確認：具体的にどのような点でうまくいかなかったか伺う。
3. 事実整理：その内容を踏まえ、今回の提供内容のどの部分が対応できる可能性が
   あるかを伝える（実行するのは最終的に自社であるという点は変わらないことも
   正直に伝える）。
4. 再質問：同じ失敗を避けるために、どんな条件が整っていれば進めやすいか伺う。
5. 判断確認：その条件をこの場で確認できるか確認する。

### 14. 「成果保証がない」

1. 共感：保証がないと不安に感じるのは当然だと伝える。
2. 理由確認：どのような保証があれば安心できそうか伺う。
3. 事実整理：この商品は成果を保証するものではないことを正直に伝える。
   保証がない代わりに、投資回収の考え方を事前に一緒に試算し、現実的な
   見通しを持ってもらうことを重視していることを伝える。
4. 再質問：保証がない中で判断するとしたら、何を基準に決めるのが納得感が
   あるか伺う。
5. 判断確認：その基準に照らして今回の試算・内容は納得できるか確認する。

### 15. 「具体的な提供内容が分からない」

1. 共感：内容が具体的に見えないと判断しづらいのは当然だと伝える。
2. 理由確認：特にどの部分が分かりにくいか伺う。
3. 事実整理：第8章の表を使ってカテゴリーごとに再確認する。未確認項目は
   「想定される項目であり、最終内容は契約前の書面で確認できる」と正直に伝える。
4. 再質問：特に詳しく知りたい項目はどれか伺う。
5. 判断確認：その項目について契約前に書面で確認する形で進めてよいか確認する。

## 第15章　クロージング

「今すぐ決めないと損をする」といった根拠のない煽りは使いません。一方で、
話を曖昧なまま終わらせず、必ず「進める」「条件を確認して進める」
「今回は見送る」のいずれかを明確にして面談を終えます。

### テストクロージング

「ここまでの内容を踏まえて、率直に伺いたいのですが、今回の内容は御社に
とって取り組む価値があると感じられますか。」

### 商品適合の確認

第13章の判定を念頭に、「この取り組みは御社に必要性が高いと感じますか」を
確認する。

### 意思決定者の確認

「この場でご判断いただける内容でしょうか。それとも他にご確認が必要な方が
いらっしゃいますか。」

### 残っている不安の特定

「進めるとしたら、という前提で伺いますが、今の時点で気になる点はありますか。」
出てきた内容は第14章を使って対応する。

### 投資回収の確認

第10章のROIシミュレーションを再度確認し、「この試算の前提は現実的な数字だと
感じますか」を確認する。「これはあくまで試算であり、成果を保証するものでは
ありません」という一文を必ず伝える。

### 支払条件の確認

金額・税込税別・分割条件・支払方法・契約期間は［販売元へ要確認］。確認できて
いない条件をその場で作って答えない。「詳細な支払条件については契約書面で
正式にご案内します」と伝える。

### 導入時期の確認

「実際に始めるとしたら、いつ頃からがよさそうですか」を確認する。

### 最終意思確認

「ここまでの内容を踏まえて、今日この場で進めるご判断をいただけそうですか。」

- **進める** → 契約手続きの案内に進む。次回連絡日・必要書類・支払方法を
  明確にして終える。
- **条件を確認して進める** → 何を、誰が、いつまでに確認するのかを具体的に
  合意し、次回連絡日を必ず設定する。
- **今回は見送る** → 見送りの理由を確認し、無理に引き止めない。今後の
  情報提供の可否を確認して丁寧に終える。

### 保留時の対応

1. 保留の理由を具体的に確認する
2. 該当する反論項目（第14章）で対応する
3. 「いつまでに」「何が分かれば」判断できるかを相手の言葉で確認する
4. 次回連絡の日時をその場で具体的に決める
5. 双方が準備・確認すべき点を明確にする

### 再面談を設定する条件

1. 次回の日時を具体的に決める（日付と時間）
2. 可能であれば意思決定者本人の同席を依頼する
3. 相手側が確認しておくべき点を明確にする
4. 自社側が準備・確認しておくべき点を明確にする
5. 再面談の議題を簡単に共有する

再面談が設定できない場合は、無理に約束を取り付けようとせず、「今回は見送る」
という判断として正直に受け止めます。

## 第16章　営業上の禁止表現

以下の表現は、いかなる場面でも使用しないでください。

- 必ず補助金が出る
- 誰でも対象になる
- 実質無料になる
- 必ず儲かる
- 確実に回収できる
- 必ず単価が1.5倍になる（裏付けとなる事例・期間・母数が確認できるまで）
- 価格競争から完全に脱却できる
- 資産価値が必ず上がる
- 全国で同じ成果が出る
- 今契約しないと損をする
- 架空の実績
- 架空のお客様の声
- 未確認の提供サービスの断定的な記載
- 未確認の成果保証
- 未確認の返金保証

また、成約率50〜60％という数値は内部参考値です。分母・対象期間・母数が
確認できるまで、顧客向けの会話・資料のいずれにも一切使用しないでください。
営業担当者が受け取る紹介報酬・営業報酬も、いかなる場面でも顧客に伝えないで
ください。

## 第17章　販売元へ確認する事項

営業開始前に、以下を販売元に確認し、チェックしてください。

- [ ] 正式商品名
