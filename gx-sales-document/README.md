# gx-sales-document ― GX営業コンテンツ 商品理解・営業実践マニュアル

営業担当者が、約160万円のGX営業コンテンツを正しく理解し、無料セミナー後の
個別相談からクロージングまで活用するための、縦スクロール型のWeb資料一式です。
16:9のスライドではなく、A4縦の文書として読む／印刷することを前提にしています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 資料の本体。ブラウザで直接開いて使う |
| `styles.css` | 画面表示用・A4印刷用のスタイル |
| `script.js` | 目次の開閉、現在位置表示、ページ上部へ戻る、開閉式台本の補助、ROI計算、印刷時の全展開 |
| `document-source.md` | `index.html` と同じ内容を、修正しやすい形で保持したMarkdown原稿 |
| `README.md` | このファイル |

## 資料の開き方

`index.html` をブラウザ（Chrome、Edge、Safariなど）で直接ダブルクリックして
開いてください。インターネット接続や特別なソフトは不要です。外部ライブラリにも
依存していません。

- PC：画面左側に目次が常に表示されます（追従表示）。
- スマートフォン・タブレット：画面上部の「目次」ボタンを押すと、目次が
  開きます。目次のリンクを押すと該当の章に移動し、自動的に目次は閉じます。
- 読んでいる章に応じて、目次内の該当項目がハイライトされます。
- 画面右下の「↑ 上部へ」ボタンで、ページの一番上に戻れます。
- 第1章の逐語台本、第14章の反論対応、第15章のクロージング台本は、
  クリックすると開閉します（＋／−のアイコンが目印です）。

## PDFへの保存方法

1. `index.html` をブラウザで開く
2. ブラウザの印刷機能を開く（Windows／Chromeの場合は `Ctrl + P`、
   Macの場合は `Cmd + P`）
3. 出力先（送信先）を「PDFに保存」に変更する
4. 用紙サイズが「A4」になっていることを確認する
5. 保存を実行する

印刷（PDF化）すると、画面上のナビゲーション（目次・ボタン）は自動的に
非表示になり、開閉式の台本（第1章・第14章・第15章）はすべて展開された
状態で出力されます。各章は新しいページから始まり、見出しがページ末尾に
単独で残ったり、表が不自然に分断されたりしないよう調整しています。

## 内容の修正場所

- 文章の内容を修正する場合は、まず `document-source.md` を編集し、その後
  `index.html` の対応する章（`<section id="chXX">`）に同じ修正を反映して
  ください。両方のファイルが同じ内容を保つことを前提にしています。
- デザイン（配色・余白・表の見た目など）を変更する場合は `styles.css` を
  編集してください。使用している色は以下の通りです。
  - ネイビー：`#101F5A`
  - ゴールド：`#B88A32`
  - ダークレッド：`#A82024`
  - アイボリー：`#F7F4EC`
  - 本文文字色：`#20242C`
  - 薄い罫線：`#D9D4C8`
- 目次の開閉・現在位置のハイライト・ROI計算・印刷時の展開などの動作を
  変更する場合は `script.js` を編集してください。

## 金額や制度情報を更新する方法

1. `index.html` 内で該当箇所を検索してください。目安は以下の通りです。
   - 価格・支払条件：第2章、第15章、`<span class="tbc">` が付いている箇所
   - 制度情報（省エネ基準・補助制度）：第3章、巻末資料の「出典一覧」
   - 160万円の提供内容：第8章の表
2. 数値や制度内容を修正したら、`<span class="tbc">販売元へ要確認</span>` の
   表記を、確認が取れた内容に置き換えてください。確認が取れていない項目は
   このタグを残したままにしてください。
3. `document-source.md` の対応箇所も同様に修正し、2つのファイルの内容を
   一致させてください。
4. 制度の出典URLを更新する場合は、巻末資料「出典一覧」の該当行と、
   本文中の脚注番号（`<sup class="fn">`）の対応関係が崩れていないか
   確認してください。

## 販売元への確認事項が記載されている場所

- 第2章：商品の位置づけに関する未確認事項
- 第8章：160万円の提供内容ごとの確認状況（表の最終列）
- 第17章：販売元へ確認する事項の全体チェックリスト
- 巻末資料「出典一覧」：制度情報の出典と確認状況
- 巻末資料「販売元への確認事項一覧」：第17章と同一のチェックリスト

営業を開始する前に、必ず第17章と巻末資料のチェックリストを販売元と
突き合わせ、確認が取れた項目から `<span class="tbc">販売元へ要確認</span>`
の表記を外していってください。

## 注意事項

- 成約率50〜60％、営業担当者の紹介報酬・営業報酬などの内部情報は、本資料
  にも一切記載していません。これらは別の内部資料でのみ扱ってください。
- 「必ず儲かる」「必ず単価が1.5倍になる」等の断定表現は、第16章に
  禁止表現として明記しています。修正・追記の際もこの方針を維持してください。
