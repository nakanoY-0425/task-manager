# パーソナルトレーナー向けコンサル・スクール ナレッジ構成表（サマリー版）

集客→商品設計→カウンセリング・セールス→継続・顧客満足度→数字管理→仕組み化、という流れで整理した初期のカリキュラム構成案。
より詳細で実運用（AI診断）を前提としたナレッジは `A-business-knowledge.md`（経営・集客・セールス50項目）と
`B-client-knowledge.md`（クライアント向けトレーニング・食事・習慣化50項目）を参照。

## 0. コンセプト

**ゴール：** トレーニングを教えるのではなく、「トレーナーが自分の力で安定して売上を作れる状態」を作ること。

集客 → 商品設計 → カウンセリング → セールス → 成約 → 継続 → 紹介 → 数字管理 → 仕組み化 → 自分が働かなくても売上が立つ状態

## モジュール1｜集客

- SNS集客：Instagram集客／TikTok・YouTube集客
- 導線設計：LINE公式への誘導／SNSから体験・カウンセリングへの導線設計
- その他チャネル：紹介による集客／MEO・地域集客
- 発信設計：プロフィール設計／投稿コンテンツの作り方／見込み客が増える発信
- 考え方：フォロワー数ではなく「見込み客」を増やす発想への転換

## モジュール2｜商品設計

- 契約形態：単発セッション→期間契約への移行／3ヶ月・6ヶ月などの長期プラン設計
- 商品ライン：トレーニング＋食事指導／オンライン＋対面のハイブリッド／高単価商品／継続課金商品／アップセル商品
- 設計思想：顧客の悩みから逆算した商品設計／競合との差別化／価格設定

## モジュール3｜カウンセリング・セールス

基本構成（フロー順）：アイスブレイク→現状のヒアリング→悩みの深掘り→過去に失敗した原因の確認→理想の未来を明確にする→現状と理想のギャップを認識してもらう→問題解決に必要なことを整理する→商品・サービスの提案→価格提示→クロージング

切り返しトーク：「高い」「考えます」「お金がない」「家族に相談する」への対応

セールスの質：成約率を上げる質問設計／押し売りにならないクロージング／成約後のフォロー

## モジュール4｜継続・顧客満足度

- 満足度向上：成果の見える化／定期的な目標設定／食事・生活習慣のサポート／トレーニング以外の価値提供
- 関係構築：顧客との信頼関係構築／退会率を下げる方法
- 紹介・口コミ：紹介が自然に発生する仕組み／口コミを増やす方法
- 追加収益：継続契約につなげる方法／アップセル・追加商品の提案

## モジュール5｜数字管理（売上・経営）

追うべき指標：新規顧客数／体験数／問い合わせ数／成約率／客単価／継続率／月商／LTV／紹介率／稼働率／粗利／経費／利益率

**売上逆算の考え方**：売上を「問い合わせ数 × 体験率 × 成約率 × 客単価」に分解し、ボトルネックの数字を特定する思考法を教える。

```
月商100万円が目標 ÷ 客単価15万円 ＝ 新規契約7人が必要
÷ 成約率35% ＝ 体験20件が必要
÷ 体験率50% ＝ 問い合わせ40件が必要
```

## モジュール6｜仕組み化（売上ステージ別ロードマップ）

| ステージ | 月商目安 | やること |
|---|---|---|
| Stage1 | 〜30万円 | 顧客獲得／セッション提供の基本／SNS発信／初回カウンセリング |
| Stage2 | 〜50万円 | 単価アップ／成約率改善／継続率改善／紹介獲得 |
| Stage3 | 〜100万円 | 高単価商品の設計／集客導線の構築／セールスの仕組み化／LTV向上 |
| Stage4 | 〜200万円 | スタッフ採用／業務委託／オンライン商品の導入／自分の稼働時間を減らす |
| Stage5 | 300万円〜 | 店舗展開／トレーナー育成／スクール化／コンサル事業／オンライン事業／自分が現場に立たなくても回る仕組み |
